# SPX 数据层（yfinance）

**时间**：2026-07-22 03:14  
**背景**：为 Market Cycle 框架建立可复现的美股标普点位数据层；非交易执行，主序列用指数而非 SPY。

**关键决策**：
- v1 边界 → **仅单指数价格层**（备选：多指数 / 价格+量能广度）— 理由：先闭环 SPX 日线；量能另源，不绑在指数 volume 上
- 主序列 → **^GSPC（SPX 现金指数）**（备选：SPY ETF）— 理由：框架语义对准市场点位，非可交易代理
- 数据源 → **yfinance**（备选：OpenBB）— 理由：轻量够用；OpenBB 留待多源/宏观中台
- 历史长度 → **全量可获日线**（备选：1950/1980 起）— 理由：存储可忽略；截窗是分析参数不是采集参数
- 频率 → **只存日线**；周线由日线 resample（备选：日+周双拉）— 理由：单一权威源，避免 Yahoo 日/周不一致
- 更新策略 → **全量覆盖写盘**；生产增量以后再做（备选：增量追加 / 仅手动更新）— 理由：当前为形成框架，无需日更
- 存储 → **`data/raw/spx_daily.parquet`**（备选：CSV / 双写）— 理由：类型稳、单文件权威缓存
- 字段 → **`date, open, high, low, close`**（备选：+volume / yfinance 全列）— 理由：最小价格层；不用指数 volume 当市场量
- 对外 API → **`get_bars(symbol=..., refresh=False)`**；v1 仅实现 SPX（备选：`get_spx_daily` / Store 类）— 理由：预留多 symbol 形态，v1 收紧实现
- 无缓存 + `refresh=False` → **自动全量拉取并 warning**（备选：硬报错 / 静默拉）— 理由：可跑通且知情联网
- `refresh=True` 失败 → **硬失败**，不回退旧缓存（备选：stale + 警告）— 理由：显式刷新不得假成功
- 符号 → **规范 `^GSPC`，别名 `SPX`/`GSPC`/`^GSPC`**（备选：只认 ^GSPC）— 理由：口语自然 + 内部唯一 id

**默认约定（未单独表决，可反对）**：
- 日期为朴素交易日 `date`（无时区）
- yfinance 使用 `auto_adjust=False`，OHLC 作指数点位
- v1 不提供公共 `get_weekly`；分析层需要时 resample
- 不引入 OpenBB；依赖放项目 venv（yfinance/pandas/pyarrow）

# SPX Brooks Market Cycle 研究计划

本文维护当前研究问题、阶段、假说和开放问题。已确认架构以
[decisions.md](decisions.md) 为准；概念边界以 [foundation.md](foundation.md) 为准；
公式候选以 [brooks-measurement-candidates.md](brooks-measurement-candidates.md) 为准。

## 1. 当前阶段

当前研究 SPX 日线 OHLC 上的 Brooks-inspired 市场过程表示，不构建 O'Neil、横截面
或交易系统。完整复刻 Brooks 还是建立 Brooks-inspired 表示仍是
[Q-001](#q-001-研究目标是-brooks-复刻还是-brooks-inspired-表示)。

已经完成：

- `^GSPC` 日线 OHLC 缓存、不可变快照、质量报告和资格规则；
- Phase 1A 共享尺子 `tr_pct` / `atr_pct_14`；
- `BM-E-01-OHLC-min v1` 多尺度效率的纯计算实现、性质测试和前缀重放测试；
- `bm_g_01_atr_reversal_v1` 的候选、确认、失效与 `as_of` 因果实现，现保留为
  `structures` 下的未来结构候选，不属于 Phase 1A 基础层；
- 本地连续行为审计页，用于 K 线、效率尺度和严格 `as_of` 回放。

当前操作位置是 **Phase 1A 开发块：基础连续行为表示**。依据 D-013，当前只研究
固定窗口、多尺度、无需显式腿或摆动起点的连续行为量。当前不研究当前腿、回调、
Episode、通道、三推、双底或任何结构相对特征。

尚未完成：

- 轨道 A 真实窗口的高/中/低效率开发审计；
- 方向、双向性、重叠和扩张等连续行为量的操作定义与实现；
- 连续行为层的选择块、锁定确认块和状态压缩判断；
- 路径与形态结构的独立 Phase 2 协议。

## 3. 研究目标

当前主问题是：

> 只使用截至当日收盘的 SPX 日线 OHLC，固定窗口、多尺度连续行为量能否形成稳定、
> 可审计、跨尺度的基础价格过程底图；在此基础上，是否值得以可接受的信息损失压缩为
> 更简洁的市场状态表示？

连续特征描述截至当日已经发生的区间，不承担未来腿起点、状态转换或交易结论。基础
层必须显式声明窗口、公式、版本和 `as_of`；但“时间参考系显式”不等于“路径分段
必须基础化”。

## 4. 工作假说

### H-001 多尺度连续行为表示可构成基础价格过程底图

- **状态**：`HYPOTHESIS / UNTESTED`
- **陈述**：固定窗口、多尺度的方向、效率、双向性、重叠和扩张量能够稳定描述已发生
  的价格过程，并提供足以支持后续状态压缩的连续证据。
- **支持条件**：各量逐日前缀重放一致；合理窗口变化下语义稳定；在连续时间块内能够
  以可解释方式区分持续推进、双向往返和扩张过程；新增连续量相对已有尺度场有明确
  信息保留价值。
- **否定条件**：窗口族极端敏感、连续特征无法表达研究目标所需的关键过程，或进入
  结构语义前已出现无法通过连续历史恢复的明确缺口。

### H-002 持续体制与转换过程应分开

- **状态**：`HYPOTHESIS / UNTESTED`
- **陈述**：`BALANCE/DIRECTIONAL` 更像持续体制，`EXPANSION/REBALANCING` 更像转换
  过程；这种表示优于四个并列互斥状态。
- **前置条件**：H-001 至少保留一组稳定连续表示后才可检验。

### H-003 SPX 日线适合作为低干扰实验台

- **状态**：`HYPOTHESIS / UNTESTED`
- **陈述**：SPX 相比预先选定的高流动性个股样本，受公司特有跳空和流动性干扰更少，
  因而适合作为初步连续测量定义的实验台。
- **限制**：指数平滑可能制造虚假清晰；SPX 内部有效不代表个股、盘中或其他指数可迁移。

### H-004 结构解析可能在明确形态问题上补充连续底图

- **状态**：`HYPOTHESIS / DEFERRED TO PHASE 2`
- **陈述**：若研究问题明确需要腿、回调、区间边界、通道、三推或双底，因果结构解析
  可能补充连续行为层无法表达的关系信息。
- **约束**：该命题不预设当前 ATR 反转路径正确，也不允许在 Phase 1 使用未定义结构
  术语。Phase 2 必须从具体语义缺口出发比较结构候选。

## 5. Phase 1A：基础连续行为表示

### 5.1 范围

只做：

- SPX 日线 OHLC；
- 固定窗口、多尺度连续表示；
- 同一连续行为在多个日历尺度上的稳定性、信息保留和解释比较；
- 严格 `as_of` 回放、连续时间块验证和复杂度控制；
- 可选的初级状态压缩准备。

明确不做：

- 路径锚点、候选、确认、失效、当前腿、回调和 Episode；
- 多尺度摆动树、通道、双底、三推、形态图语法；
- 通用 Episode 平台、交易信号、仓位和组合优化。

### 5.2 共同时间契约

每个连续量必须记录：

```text
reference_type    fixed_calendar_window
window            包含当日在内的交易日根数
as_of             窗口结束日收盘后可用
feature_version   公式与实现版本
```

固定窗口、规则事件和路径分段可以在系统中并存，但它们是不同参考系。当前 Phase 1A
只使用第一类；不能用未来形成的结构解释历史窗口，也不能把连续值命名为未定义的腿。

### 5.3 当前实现：OHLC-min 多尺度效率

对每根日线，定义与前收和 OHLC 相容的最短可见路径：

$$
L_i^{\min}
=
|O_i-C_{i-1}|
+
\min
\begin{cases}
|O_i-H_i|+|H_i-L_i|+|L_i-C_i|,\\
|O_i-L_i|+|L_i-H_i|+|H_i-C_i|.
\end{cases}
$$

固定窗口效率为：

$$
E^{\mathrm{OHLC\text{-}min}}_{t,n}
=
\frac{|C_t-C_{t-n}|}
{\sum_{i=t-n+1}^{t}L_i^{\min}},
\qquad n\in\{5,10,20,55\}.
$$

`L_min` 是 OHLC 可确定路径的下界，效率是未知真实日内效率的上界。当前窗口族从
1984-05-01 起齐套。多个窗口共同构成尺度剖面，不得从历史结果中挑一个最好看的窗口
后冒充唯一正确尺度。

### 5.4 开发与选择

开发块检查公式性质、前缀重放一致性和真实窗口语义；典型图表用于发现反例，不是
正式通过证据。

选择块必须使用预先划定的连续时间段，检查：

1. 不同窗口的稳定性和尺度关系；
2. 连续量对方向推进、双向往返和扩张的描述覆盖；
3. 新连续特征相对已有尺度场的信息保留；
4. 复杂度、维度和解释成本是否值得；
5. 基础连续层是否足以进入状态压缩，或明确缺少何种语义。

不得以未来收益或视觉美观选择窗口。若发现连续层有明确语义缺口，记录缺口后再在
Phase 2 设计结构协议；不得自动将现有 ATR 路径作为补救。

### 5.5 Phase 1A 可能结论

```text
连续层足够：保留多尺度连续表示，进入可选状态压缩。
连续层不足：明确缺少的语义或关系，Phase 2 为该缺口设计结构研究。
连续定义不稳：修正公式或窗口协议后重做。
实验无效：因果回放、数据或冻结协议失败，修正后重做。
```

## 6. Phase 1B：可选状态压缩

只有 Phase 1A 至少保留一组因果、稳定的连续表示后，才比较：

```text
A. 原始连续多尺度表示
B. BALANCE / DIRECTIONAL 持续体制 + 转换事件
C. BALANCE / EXPANSION / DIRECTIONAL / REBALANCING + UNRESOLVED
```

状态压缩的目标是以可接受的信息损失换取稳定、可审计和可解释的接口；若没有收益，
保留连续表示。Phase 1B 不因结构代码存在而读取路径锚点。

## 7. Phase 2：路径与形态结构解析

Phase 2 在出现明确结构表达需求时立项，研究：

- 推进腿、回调腿与其因果边界；
- 区间边界、价格占用和接受区域；
- 紧密、普通和宽通道；
- 多次推进、三推、双底和结构嵌套。

候选包括当前 `bm_g_01_atr_reversal_v1`、多尺度 Directional Change、分段线性表示、
摆动树和图语法。它们都不是默认市场本体；必须比较候选/确认时间、参数稳定、重绘、
语义覆盖、信息保留和复杂度，并证明补充的是连续底图无法恢复的信息。

## 8. 开放问题

### Q-001 研究目标是 Brooks 复刻还是 Brooks-inspired 表示

- **状态**：`OPEN`
- **当前推荐**：后者；Brooks 语义是候选来源，不以完整复刻为验收。

### Q-002 四阶段如何组织

- **状态**：`OPEN`
- **关闭条件**：Phase 1A 保留连续表示后，再比较状态压缩的信息损失、稳定性和解释收益。

### Q-004 连续窗口尺度与后续结果期限

- **状态**：`OPEN`
- **已对齐**：当前效率窗口 `{5,10,20,55}` 是观察分辨率，不是市场天然周期；共同
  齐套日为 1984-05-01。
- **剩余约束**：其他连续特征的尺度和状态压缩的验证期限尚未决定。

### Q-005 是否需要人工冻结图表标注

- **状态**：`OPEN`
- **价值**：检验连续行为语义和执行一致性；不替代条件行为验证。

### Q-006 什么证据足以进入下一阶段

- **状态**：`OPEN`
- **原则**：关注连续时间块中的稳定性、语义覆盖、信息保留和相对强基线的增量；
  确认块前写出正式统计协议。

### Q-007 后续成交量和横截面数据来源

- **状态**：`OPEN / DEFERRED`
- **约束**：现金指数没有可靠自身成交量；O'Neil 需要独立市场量、宽度和领导力。

### Q-008 Phase 1A 采用哪种最小因果路径表示

- **状态**：`SUPERSEDED`
- **说明**：D-013 将路径结构移出 Phase 1A 基础层。`bm_g_01_atr_reversal_v1` 保留为
  Phase 2 的因果结构候选，不再是 Phase 1A 问题。

### Q-009 Phase 2 采用哪种路径与形态结构表示

- **状态**：`OPEN / DEFERRED`
- **候选**：当前 ATR 反转路径、多尺度 Directional Change、分段线性表示、摆动树、
  图语法和价格区域表示。
- **关闭条件**：明确结构语义缺口后，依据连续层残差预注册比较协议。

## 9. 本阶段预期产物

Phase 1A 的产物是：

1. 连续行为特征的版本化定义与前缀重放测试；
2. 多尺度连续表示的开发、选择和锁定确认记录；
3. 说明连续层足够、缺少何种结构语义、连续定义不稳或实验无效的明确结论；
4. 若进入 Phase 2，一份从具体语义缺口出发的结构解析研究协议。

它不以拥有路径算法、形态标签或彩色状态曲线为完成标志。

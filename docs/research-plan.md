# SPX Brooks Market Cycle 研究计划

首次了解项目整体研究顺序、阶段理由和分叉路径，先读
[research-guide.md](research-guide.md)。本文负责当前研究假说、协议边界和开放问题。

## 1. 当前阶段

依据 [D-003](decisions.md#d-003-先在-spx-日线上研究-brooks-market-cycle)，
当前优先研究 SPX 日线上的 Brooks Market Cycle。本文暂用 `Brooks-inspired`
称呼候选量化表示，以免把项目抽象冒充原体系；这不代表已经决定放弃完整复刻，
最终研究目标仍由 [Q-001](#q-001-研究目标是-brooks-复刻还是-brooks-inspired-表示)
关闭。当前也不是在构建 O'Neil、横截面或交易系统。

已经完成：

- `^GSPC` 日线 OHLC 获取和 parquet 缓存；
- 从日线重采样周线；
- 原始参考对话归档和权威文档分层。

尚未完成：

- Brooks 行为特征；
- 路径事件；
- 状态或转换规则；
- 研究标签、前向结果和基线；
- 因果回放、参数稳定性和样本外验证。

当前操作位置是 Phase 0 收口和 Phase 1A 准备：下一步先形成正式数据质量报告、
数据快照标识和工作协议初稿，再开始基础测量与事件实现。探索期允许公式和参数
显式版本化迭代；进入锁定确认块前再冻结正式协议。

因此，任何“当前 SPX 是 `REBALANCING`”之类的结论都没有模型版本和证据支持，
只能视为示例，不是项目事实。

## 2. 数据事实与约束

当前 `data/raw/spx_daily.parquet` 的审计结果：

```text
symbol: ^GSPC
frequency: daily
columns: date, open, high, low, close
rows: 24,754
range: 1927-12-30 through 2026-07-21
volume: unavailable by design
```

质量约束：

- 1927-12-30 至 1961 年末的 8,509 根记录为退化 OHLC，四个价格相同；
- 1962 年以后还有 38 根零区间记录，最后一根为 1983-06-30；
- 1962 年以后共有 16,245 根记录；1984 年以后共有 10,720 根且无零区间；
- 退化记录可用于某些 close-only 研究，但不能用于实体、影线、重叠或 TR 特征；
- 原始数据层应保存全量事实，研究层决定有效样本，不能伪造缺失的日内区间；
- 正式实验前需要冻结数据哈希、截止日期和质量规则，防止刷新后历史静默变化。

主样本从 1962 年开始并质量过滤，还是从 1984 年开始获得完全干净的 OHLC，仍是
[Q-003](#q-003-主研究样本从何时开始)。

## 3. 研究目标

### 3.1 推荐的主问题

> 在每日收盘时点，只使用截至当日的 SPX OHLC，Brooks-inspired 连续行为特征
> 和少数路径事件，能否稳定区分后续价格路径，并提供超越简单趋势、波动率和
> 路径效率基线的增量信息？

这是一项价格过程表示研究，不是点位预测或交易收益优化。研究前向路径的原因是
防止循环自证：用当期效率定义 `DIRECTIONAL`，再证明它当期效率较高，没有提供
任何外部证据。

前向行为不是唯一合法性标准，但有否决权。一个复杂表示即使语义优美，若不能
稳定复现、不能压缩信息，也不能改变条件路径分布，就没有成为量化模块的理由。

### 3.2 明确区分三种目标

| 目标 | 评价方式 | 当前地位 |
|---|---|---|
| 形式化 Brooks 语义 | 冻结图表和独立执行一致性 | 辅助，不是主目标 |
| 模仿某位专家 | 专家标签复现率 | 不在当前范围 |
| 检验 Brooks-inspired 表示 | 样本外条件路径和增量价值 | 推荐主目标 |

## 4. 工作假说

### H-001 连续行为与路径事件具有增量信息

- **状态**：`HYPOTHESIS / UNTESTED`
- **陈述**：方向、效率、双向性、扩张、回调衰减等连续变量，加上突破后的跟进、
  失败和再平衡事件，能够区分 SPX 日线后续路径，且不是简单动量或波动率的别名。
- **支持条件**：锁定时间块中，路径事件在强基线条件下仍改变后续保留、回调、
  同向持续或重新入区间的分布。
- **否定条件**：结果只在开发样本存在；方向跨时间块反复；强基线已解释全部差异；
  区块置乱后的假事件同样有效。

### H-002 持续体制与转换过程应分开

- **状态**：`HYPOTHESIS / UNTESTED`
- **陈述**：`BALANCE/DIRECTIONAL` 更像持续体制，`EXPANSION/REBALANCING`
  更像转换过程；这种表示优于四个并列互斥状态。
- **比较对象**：连续表示；两种持续体制加转换事件；互斥四阶段加 `UNRESOLVED`。
- **否定条件**：分层表示没有增加稳定性或解释力，反而丢失关键路径信息。

### H-003 SPX 日线适合作为低干扰实验台

- **状态**：`HYPOTHESIS / UNTESTED`
- **陈述**：在同一日线表示下，SPX 相比预先选定的高流动性个股样本，会受到更少
  的公司特有跳空和流动性干扰，因而更适合建立初步测量和事件定义。
- **限制**：指数平滑可能制造虚假清晰；通过 SPX 内部验证不代表个股、盘中或其他
  指数可迁移。
- **否定条件**：后续使用相同规则比较时，SPX 并未表现出更低的事件特有噪声或
  更高的定义稳定性；或者所谓清晰度主要是平滑造成，参数轻微变化后仍会消失。

### H-004 结构层能补充基础表示遗漏的路径信息

- **状态**：`HYPOTHESIS / DEFERRED TO PHASE 2`
- **陈述**：滚动行为变量和少数事件可以形成第一阶段基线，但较完整地表达 Brooks
  的通道、腿、多次推进和成熟过程，需要显式路径或形态结构；结构层将补充基础表示
  无法保留的信息。
- **比较对象**：无骨架基线；单尺度因果摆动；多尺度 Directional Change；分段
  线性表示；多尺度持久性结构。
- **支持条件**：至少一种预注册结构表示稳定改善语义覆盖、Episode/腿的复现、
  历史信息保留、参数稳定性或条件路径区分中的一项，且没有以不可接受的重绘和
  复杂度为代价。
- **否定条件**：合理的结构候选在上述维度均无稳定改善，或所有改善都依赖未来
  回填、极端参数敏感性或不可复现的人工裁决。

### H-005 个体周期分布能扩展传统市场宽度

- **状态**：`HYPOTHESIS / DEFERRED`
- **陈述**：未来对个股、行业和领导股独立估计 Market Cycle 后，状态存量和迁移流
  能比“位于均线上方比例”等传统宽度提供更细的内部结构信息。
- **否定条件**：复杂状态场相对简单宽度、动量和行业扩散没有稳定增量。

## 5. Phase 1A：测量与路径语法探针

### 5.1 范围

只做：

- SPX 现金指数；
- 日线 OHLC；
- 一个预先声明的研究尺度及有限的稳健性尺度；
- 因果连续特征；
- 少数可被否定的路径事件；
- 条件路径和简单基线比较。

明确不做：

- 完整四状态生产引擎；
- 未校准的 confidence 或概率；
- ZigZag、多尺度摆动树、价格接受密度场；这些明确延至 Phase 2，不代表长期不需要；
- HMM、聚类、变化点融合；
- O'Neil FTD 和派发；
- 多时间周期、个股、宽度和领导股；
- 买卖、仓位和组合优化。

### 5.2 连续行为轨

第一批只保留少量、可审计的特征族：

1. 方向偏置：稳健斜率、净位移方向或高低点有序程度；
2. 路径效率：净位移相对于累计绝对变动；
3. 双向性：K 线重叠、涨跌交替、均值或中心穿越；
4. 扩张：相对于历史边界的逃逸与 TR/ATR 异常；
5. 回调/衰减：顺势结构中的反向深度、持续和效率下降。

这些特征的归档原式、复合定义和补充风险说明见
[Brooks 测量候选目录](brooks-measurement-candidates.md)。Phase 1 不是从空白重新
发明公式，而是从目录中选择当前 OHLC 可支持、时点因果且可审计的候选；目录中的
公式也不会因为被保存就自动成为默认实现。

特征公式、窗口和标准化方式必须版本化，但探索阶段允许显式迭代。进入锁定验证块
以前，再冻结公式、参数和主假说；不能把正常探索和事后改写混为一谈。

### 5.3 路径语法轨

只测量连续特征容易退化成“趋势会短期持续”的常识检验，因此同一阶段还需要少数
Brooks-specific grammar probes：

```text
ESCAPE
价格因果地离开此前边界。

FOLLOW_THROUGH / FAILED_ESCAPE
离开后能否在预定窗口内保留进展，还是重新进入原区间。

DEEPENING_PULLBACK
方向尚存时，回调加深、双向性上升和效率下降是否意味着再平衡风险。
```

这些首先是事件断言，不是完整状态机。每个平衡 Episode 后的首次逃逸作为事件
样本，避免连续多天把同一次突破重复计算成独立事件。

### 5.4 前向结果

不能只看未来涨跌。候选结果包括：

- 按当时方向签名的未来路径效率；
- 逃逸后位于旧边界外的时间比例；
- 突破进展的保留率；
- 最大顺向和逆向路径；
- 回调深度和持续时间；
- 重新进入原区间或建立新平衡所需时间；
- 状态或事件的生存时间。

研究尺度与前向期限必须先声明并成比例报告，不能从大量期限中事后挑最好结果。

### 5.5 强基线

最低比较集包括：

1. 无条件历史分布；
2. 历史收益方向和实现波动率；
3. 均线或滚动回归斜率；
4. 单独的路径效率比率；
5. 波动率分位；
6. 区块置乱后的假事件。

若路径事件不能在这些基线之上提供稳定增量，优先接受负结论，而不是增加更多
状态、形态或例外规则。

### 5.6 因果与验证要求

1. 数据快照、质量规则和配置可追溯；
2. 所有边界只由 `t-1` 或更早信息建立，当日 K 线只能在收盘后生效；
3. 候选、确认、有效和失效时间分开；
4. 同一截至日的增量计算与批量计算一致；
5. 不随机拆分相邻日线；使用连续时间块、purge 和区块重采样；
6. 开发、选择和锁定确认块分开，确认块禁止修改定义；
7. 参数按各自自然尺度预声明合理网格，不统一套用伪精确的 `±20%`；
8. 典型图表只用于调试，边界和反例进入正式检查；
9. 报告效应方向、区间和跨时期稳定性，不先设无依据的 2% 或 80% 魔法门槛；
10. close-only 与完整 OHLC 版本对照，判断 K 线几何是否真正增加信息。

### 5.7 Phase 1A 停止条件

出现以下任一核心问题时，停止把基础变量直接升级为状态复杂度：

- 因果回放不一致或历史输出被未来重写；
- 事件定义对合理参数范围极端敏感；
- 预注册行为排序在锁定样本中不成立；
- 路径事件不能超越趋势、波动和效率基线；
- 置乱事件同样有效；
- OHLC 版本与 close-only 几乎相同，却仍声称 K 线几何有价值；
- 结论只存在于少数知名危机或人为挑选的典型片段。

负结论只否定当前“SPX 日线定义”，不能据此否定 Brooks 在所有市场和周期上的
全部经验主张，也不能证明路径结构没有价值。Phase 1A 负结果会阻止 Phase 1B 把
基础变量压缩成状态；除非另行决定终止整个 SPX/Brooks 研究，Phase 2 仍按预先
规划作为独立结构实验进行，而不是为挽救 Phase 1 结果事后增加的形态补丁。

## 6. Phase 1B：状态压缩

只有 Phase 1A 至少发现一个稳健的路径事件或行为组合后，才比较：

```text
A. 连续行为表示
B. BALANCE / DIRECTIONAL 持续体制 + 转换事件
C. BALANCE / EXPANSION / DIRECTIONAL / REBALANCING + UNRESOLVED
```

比较目标不是要求离散状态凭空超越原始连续特征，而是考察：

- 信息损失有多大；
- 状态是否更稳定；
- 是否更容易审计和作为下游接口；
- 转换是否保留关键路径；
- 模糊样本能否诚实进入 `UNRESOLVED`；
- 状态标签是否对不同时间块保持相同含义。

若离散状态明显丢失信息且没有稳定性或解释收益，就保留连续表示，不强建四状态。

## 7. 后续阶段

### 7.1 Phase 2：SPX 路径与形态结构

依据 [D-006](decisions.md#d-006-brooks-结构表示分阶段引入)，Phase 2 仍在 SPX
日线上研究，不立即跳到跨指数。目标是显式表达基础滚动变量难以完整保留的：

- Episode 起源与边界；
- 推进腿和回调腿；
- 紧密、普通和宽通道；
- 多次推进、三推和边际生产率；
- 回调逐步加深、通道弱化和成熟过程；
- 多尺度结构的嵌套与候选/确认时间。

至少保留无骨架版本作为基线，比较因果 ZigZag、Directional Change、分段线性
表示和多尺度结构。验收同时考察语义覆盖、人工或程序复现、压缩残差、参数稳定、
重绘、复杂度和条件行为；不能只挑一张图说明形态更像 Brooks。

Phase 2 完成后重新检查 Phase 1B 的表示选择：根据新增结构信息，决定保留、修订
或放弃原状态本体；若此前跳过 Phase 1B，则重新判断结构层是否支持新的状态压缩，
而不是默认必须产生四阶段。

### 7.2 远期路线

| 阶段 | 目标 | 前置门槛 |
|---|---|---|
| Phase 2 | 在 SPX 上研究路径与形态结构 | Phase 1 基线和数据边界清楚 |
| Phase 3 | 冻结规则后测试少量异质指数 | SPX 内部因果、基础和结构比较完成 |
| Phase 4 | 高流动性个股压力测试 | 跨指数语义基本稳定 |
| Phase 5 | 建立全市场、行业和领导股周期分布及迁移流 | 个体状态在个股上可用 |
| Phase 6 | 引入宽度、领导力和独立成交量代理，研究 O'Neil M | 横截面数据时点一致 |
| Phase 7 | 形成 Market Context，连接策略政策与风险预算 | 各估计器有独立增量 |

阶段不是功能清单。每一阶段都可以因证据不足而停止、简化或改写，不能默认最终
一定建成七层市场状态平台。

## 8. 开放问题

### Q-001 研究目标是 Brooks 复刻还是 Brooks-inspired 表示

- **状态**：`OPEN`
- **当前推荐**：后者；Brooks 语义作为假说来源，不以完整复刻为验收。
- **为何重要**：决定是否需要专家标签，以及结果能否使用 Brooks 名称。
- **关闭条件**：用户明确批准目标表述，并写入新决策。

### Q-002 四阶段如何组织

- **状态**：`OPEN`
- **候选**：四个互斥状态；两种持续体制加两种转换；纯连续表示。
- **关闭条件**：Phase 1A 后比较信息损失、稳定性和解释收益。

### Q-003 主研究样本从何时开始

- **状态**：`OPEN`
- **候选**：1962+ 逐行质量过滤；1984+ 完全无零区间主样本；两者主次互换。
- **关闭条件**：完成质量特征影响审计并明确主样本与敏感性样本。

### Q-004 主研究尺度和前向期限

- **状态**：`OPEN`
- **约束**：固定日线，但基础窗口、Episode 尺度和前向期限尚未决定。
- **关闭条件**：依据研究对象而非历史最好结果预声明尺度族。

### Q-005 是否需要人工冻结图表标注

- **状态**：`OPEN`
- **价值**：检验语义和执行一致性；不能替代条件行为验证。
- **资源问题**：尚未确认能否获得第二位独立且受过 Brooks 训练的标注者。
- **关闭条件**：决定是做单人延时复标、寻找第二标注者，还是放弃语义复刻目标。

### Q-006 什么证据足以进入下一阶段

- **状态**：`OPEN`
- **当前原则**：不预设无依据的固定百分比；关注锁定样本中的方向、区间、稳健性
  和相对强基线的增量。
- **关闭条件**：在查看确认样本前写出正式统计协议。

### Q-007 后续成交量和横截面数据来源

- **状态**：`OPEN / DEFERRED`
- **约束**：现金指数没有可靠“自身成交量”；O'Neil 需要独立市场量、宽度和领导力。
- **关闭条件**：Phase 5/6 立项时单独做 point-in-time 数据设计。

### Q-008 Phase 2 采用哪种路径与形态表示

- **状态**：`OPEN / DEFERRED`
- **候选**：因果 ZigZag、Directional Change、分段线性表示、多尺度摆动树，以及
  不使用显式骨架的对照组。
- **约束**：必须区分候选与确认转折点，记录可用时点，不能用未来转折回填历史。
- **关闭条件**：Phase 1 结束后预注册结构比较协议，再依据语义覆盖、信息保留、
  稳定性、重绘和复杂度选择，不在当前阶段预选工具。

## 9. 本阶段预期产物

第一阶段真正需要的产物是：

1. 一份冻结的数据质量报告；
2. 一份候选选择记录，引用 `BM-*` ID 并说明采用、拆分、延后或拒绝理由；
3. 一份短研究协议，明确公式版本、假说、结果、基线和停止条件；
4. 可逐日因果计算的少量特征和事件；
5. 逐根与批量截至当日一致性测试；
6. 开发、选择和确认结果；
7. 接受、简化或否定当前表示的结论。

它不以“已经拥有一个看起来聪明的四状态指标”为完成标志。

# Phase 1A 连续行为表示工作协议

## 1. 目的与边界

Phase 1A 建立 SPX 日线的**基础连续行为表示**。当前只研究无需显式腿、摆动或
Episode 起点的固定窗口、多尺度量：方向、效率、双向性、重叠和扩张。

第一项已实现的量是轨道 A 的 OHLC-min 路径效率。它是连续行为层的起点，不是完整的
状态机，也不预设任何 Brooks 阶段标签。

不做：因果路径分段、当前腿效率、回调比例、路径年龄、Episode、通道、三推、双底、
完整形态分类、交易信号或仓位决策。

这些对象若在后续成为明确研究问题，必须在 Phase 2 建立独立的结构解析协议。当前
`bm_g_01_atr_reversal_v1` 保留为 `structures` 下的因果摆动候选和工程资产，不属于
本协议的基础表示或比较对象。依据 D-013。

`tr_pct` 与 `atr_pct_14` 只从共享研究日表读取。当前效率实现不使用 ATR；后续需要
相对波动尺度的连续特征必须直接读取共享尺子，不能模块内重算 TR 或 ATR。

## 3. 共同时间契约

每个连续输出都有 `as_of`，且只读取截至该日收盘的数据。固定窗口测量必须声明：

```text
reference_type    fixed_calendar_window
window            包含当日在内的交易日根数
as_of             该窗口结束日收盘后可用的时点
feature_version   公式与实现版本
```

连续窗口值描述已经结束的历史区间；它不是趋势腿起点、状态转换或未来路径预测器。
窗口变化、样本起点或公式变化都必须新版本化，不能用未来信息回填当时输出。

## 4. OHLC-min 多尺度路径效率

对每根日线，定义与前收和 OHLC 相容的最短可见路径：

$$
L_i^{\min}
=
|O_i-C_{i-1}|
+
\min
\begin{cases}
|O_i-H_i|+|H_i-L_i|+|L_i-C_i|,\\
|O_i-L_i|+|L_i-H_i|+|H_i-C_i|.
\end{cases}
$$

固定窗口效率为：

$$
E^{\mathrm{OHLC\text{-}min}}_{t,n}
=
\frac{|C_t-C_{t-n}|}
{\sum_{i=t-n+1}^{t}L_i^{\min}},
\qquad n\in\{5,10,20,55\}.
$$

`L_min` 是 OHLC 可确定路径的下界，未知真实日内路径可能更长。因此效率是未知真实
日内效率的上界，不得称为完整日内效率。

若分母为零，效率缺失并标记 `zero_path`。开发期按需计算；只有连续行为层版本被
选择后，才版本化落盘宽表与元数据。当前实现输出：

```text
date
as_of
efficiency_ohlc_min_5,  efficiency_ohlc_min_5_status
efficiency_ohlc_min_10, efficiency_ohlc_min_10_status
efficiency_ohlc_min_20, efficiency_ohlc_min_20_status
efficiency_ohlc_min_55, efficiency_ohlc_min_55_status
```

多个窗口构成尺度剖面，不得从历史结果中选一个“最好看”的窗口后冒充唯一正确尺度。
5/10/20/55 日是当前预声明观察分辨率，不是市场天然周期。

## 5. 开发验收

当前效率族必须满足：

1. 单边 OHLC 路径、往返路径和零路径的手算性质测试；
2. 所有有效效率位于 $[0,1]$；
3. 批量计算与任意截至日独立重算完全一致；
4. 按高、中、低效率和四个窗口抽样真实窗口审计；
5. 审计时区分短窗口局部波动与中长窗口持续过程，不把视觉平滑度单独当作有效性证据。

后续加入方向、双向性、重叠或扩张时，每个连续特征必须补充相同级别的公式、窗口、
`as_of`、边界和重放验收，不得借用“当前腿”“回调”或未定义的结构起点解释数值。

## 6. 三个研究块

### 开发块（当前）

- 允许改正连续公式实现、补足字段、记录版本变化；
- 允许使用本地图表审计窗口语义和反例；
- 不得把调试图或个别历史片段当作状态表示有效性的结论；
- 不得因路径候选已存在而将其重新引入基础连续特征。

### 选择块（后续）

在预先划定的连续时间块中检查：

- 多尺度窗口的稳定性与尺度关系；
- 连续行为量对方向性、双向性和扩张过程的描述覆盖；
- 新连续特征相对已有尺度场的信息保留；
- 窗口族、特征维度与解释复杂度是否值得；
- 固定窗口连续行为层是否足以作为后续状态压缩的底图。

不得以最大化未来收益选择窗口。若连续表示不足，也先明确缺少的是哪种语义或信息，
再决定是否在 Phase 2 开启结构解析；不得直接把路径算法作为默认补救。

### 锁定确认块（后续）

在查看确认块前冻结：快照、样本起点、连续特征公式、窗口族、正式结果、比较基线、
停止条件和报告格式。确认块禁止改写定义；若实验无效，返回开发块并新建版本，不回填
旧结果。

## 7. 当前结论边界

本协议只定义可复现的连续价格过程实验。它尚未证明固定窗口足以构成市场状态，也不
产生 `BALANCE`、`DIRECTIONAL` 或其他市场状态，更不产生交易结论。

当前 `bm_g_01_atr_reversal_v1` 的候选、确认和锚点时间契约仍可作为未来结构研究的
因果基线，但不构成对本协议连续表示的反例、补充特征或同层对照。

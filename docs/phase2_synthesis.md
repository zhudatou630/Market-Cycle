# 第二阶段总收口：从指数到个股，Al Brooks 价格行为学在 A 股日线上到底剩下什么？

> **覆盖范围**：第一阶段（`docs/01`–`04`）+ 第二阶段方向 A（`docs/05`）、B（`docs/06`）、C（`docs/07`）、D（`docs/08b`、`08c`、`08d`）。
> **定位**：方向 D 是把第一阶段和第二阶段 A/B/C 在指数上得到的结论，搬到 5,000 多只 A 股个股上重新检验，所以本文是一份系统级的总梳理：先讲发现，再讲机制，最后讲启示与后续方向。
> **标注约定**：「发现」都是数据给出的事实；「机制」是推测；「启示」是判断。

---

## 〇、一句话总结论

**同一个 Al Brooks 形态，长在大盘、行业、个股身上，代表的是三种完全不同的东西。** 大盘和行业上的形态，反映的是资金整体的节奏（择时与轮动）；个股上的形态大多是噪音，只有少数几条反映这只股票的「风险性格」。所以个股形态能帮你躲坑，却很难帮你多赚钱。

## 一、整条研究线是怎么串起来的

| 阶段 | 研究对象 | 留下的主要结论 |
|---|---|---|
| 第一阶段 | 美股标普、A 股 31 个申万一级行业；简单平均类指标 | 没有万能的「顺势 / 逆势」开关；A 股看「位置 + 情绪温度」（高位安静慢涨稳、高位放波发烧险），缩波后的突破更稳；美股横盘起跳的突破更稳 |
| 方向 A | 突破回踩、弹簧抄底 | 指数上不灵；等回踩反而挑到弱突破 |
| 方向 B | 窄通道 vs 宽通道、三推 | A 股窄通道反而更危险；第 2 次新高强于第 3 次（9 年全胜） |
| 方向 C | 周线背景 × 日线买点 | 周线多头里挑日线买点不灵；周线休整时日线先突破，9 年 8 胜 |
| **方向 D** | **把以上全部搬到全 A 个股重考** | 见下文 |

方向 D 同时装了三面以前没有的「照妖镜」：
1. **换粒度（指数 → 个股）**：看一个形态是个股自身的微观结构，还是指数平均出来的产物。
2. **换比法（绝对涨跌 → 同一天横向比）**：绝对涨跌里混着大盘涨跌，也就是择时；同一天横向比才是纯粹的选股或选行业能力。A/B/C 的指数结论也按这种比法重算了一遍，照出了好几条结论的真面目。
3. **找「双胞胎」**：每个信号都和同一天、同一市值档、同一行业，热度、涨跌、波动都差不多，只是没有这个形态的股票比。剩下的差别，才算形态本身的本事。

最后用 `2024-11 → 2026-11` 从未碰过的个股数据做了一次性盲测。

## 二、发现（事实）

### 发现 0：个股上最大的干扰项是「热度」（`studies/08`）

- 换手高、20 天内涨停多、离均线远、出现过单日暴涨的股票，也就是最热的那 20%，之后 20 天比同类平均少赚 `0.7%~1.4%`。9 年里 8~9 年如此，主要发生在小盘股；其余 80% 的股票之间差别很小。
- 扣掉热度后，过去一两个月的涨幅反而轻微有利。A 股个股不是「涨了就跌」，而是「太热了才跌」。
- 突破、新高、强势上涨这类形态天生就热，不扣热度会把突破类形态的劣势夸大约 3 倍。

### 发现 1：Brooks 的经典买点到个股上没有复活（`studies/08b`）

| 形态 | 个股结果 | 结论 |
|---|---|---|
| 突破后等回踩再买 | 比双胞胎少赚 `0.29%`；只在小盘差，大中盘不好不坏 | 本来就不成立 |
| 弹簧（跌破前低又收回） | 和双胞胎几乎一样 | 跌破前低本身就是坏事，收回只是把坏处抹平 |
| 窄通道顺势 | 收益没差别 | 本来就不成立 |
| 周线多头里等日线回调或新高 | 比随便哪天买还差 | 指数、个股、盲测三处一致 |

这些形态在指数上失效，**不是被几十只股票平均掉了，而是在「日线、持有 20 天」这个尺度上本来就不灵。**

### 发现 2：之前的 A 股线索，被拆成了三种不同的东西（`studies/08c`）

| 之前在指数上的发现 | 用「同一天横向比」重算指数 | 到个股上 | 它其实是什么 |
|---|---|---|---|
| 第 2 次新高强于第 3 次（B） | 行业之间比依然多 `0.47%` | 差别正好是 `0` | **板块轮动节奏** |
| 周线休整时日线先突破（C） | 绝对收益多 `1.67%`，行业之间比只剩 `-0.03%` | 收益没差别 | **大盘择时** |
| 高位大盘和行业「发烧」要避开（阶段 1、Study 02） | — | 行业温度对个股选择完全没用；大盘温度方向一致但不显著 | **大盘择时** |
| 缩波后的突破更稳（阶段 1、Study 03） | 收益无差，踩雷更高 | **方向反了**：之前躁动、最近才安静的更危险 | 真正有用的是「长期一直安静」 |
| 窄通道更危险（B） | 踩雷略高 | 小盘窄通道踩雷率高 `2~3` 个百分点 | **风险性格**（跨粒度一致） |

### 发现 3：个股层面真正新增的信息只有几条，而且都是「避坑」

- **突破后回踩，守不守得住突破位**：守住的比跌破的少踩雷约 `2` 个百分点。指数上完全看不出区别，这是唯一一条「被指数平均掉」的个股结构。
- **股性**：长期躁动的股票，不管是刚安静下来还是一直躁动，突破后都更容易踩雷。

### 发现 4：两个贯穿全部考题的现象

- 小盘股的各种「创新高」信号，扣掉热度后仍比同类弱 `0.2%~0.4%`；大中盘基本中性。
- 随整个行业一起出现的形态，比单只股票独自走出来的更靠谱。

### 发现 5：盲测结果是「风险稳、收益缩」（`studies/08d`）

5 条冻结规则全部过关。所有「哪种情况更容易踩雷」的结论在新数据里都明显成立；「能多赚多少」的结论大多缩水到 `0.1%~0.3%`，方向没变，但不再显著。

## 三、背后可能的机制（推测）

### 1. 核心原理：同形不同义

```
层级     一根K线背后是谁在动                      形态反映的是
大盘     宏观、政策、整体资金进出                 何时该进退（择时）
行业     公募配置、景气、政策主题的资金轮动       轮到谁了（轮动节奏）
个股     公司消息、游资、个别大户、量化交易       这只股票的脾气（风险性格）+ 大量噪音
```

指数是几十上百只股票的平均，个股各自的噪音互相抵消，剩下的是「一大群钱一起在干什么」。所以指数上「第 2 波还是第 3 波」有意义：它描述的是一个板块处在资金进场周期的哪个阶段（新资金进场 → 扩散 → 末端接力）。单只股票的波段主要由它自己的消息和短期资金决定，按同样规则数出来的推数，已经不包含板块资金周期的信息。**不是形态在个股上失灵了，而是同样的图形，在不同层级描述的根本不是同一件事。**

### 2. 为什么 Brooks 的买点在 A 股个股日线上不灵

- **土壤不同**：Brooks 的理论主要来自美国股指期货的日内交易，那里有机构单、止损单和连续交易。A 股是 T+1、有涨跌停、散户成交占比长期过半，交易所也没有原生止损单。比如「弹簧」的核心是扫掉止损盘后反手拉回，A 股缺少这个机制。
- **散户的追涨和彩票偏好**：突破和新高最吸引追涨盘，价格容易被抬过头，之后回落。这就是小盘股新高信号偏弱的原因。
- **时间尺度不同**：Brooks 关心的是接下来几根 K 线，我们看的是 20 天，他的优势可能根本活不到 20 天。
- **大家都看得见**：日线形态公开、便宜，量化资金规模变大以后，能用的规律更容易被提前交易掉（未检验）。

### 3. 为什么「守住突破位」只在个股上有用

个股的前高是一个真实价位：上面有等着解套卖出的人，也有踏空、想回头接的人。突破后回落到这里，有人接住，说明突破背后有真实承接；一碰就破，说明突破只是被短期资金拉上去的。指数的「前高」是平均数算出来的，没有人在那个点位挂单。

### 4. 为什么「刚安静下来」反而危险：股性

波动率有一个金融学里最稳定的规律：大波动后面往往跟着大波动，而且会回到这只股票自己的长期水平。一只平时很躁动的股票短暂安静下来，多半只是在歇气。长期一直安静的股票，往往机构持股多、散户关注少，不容易被炒作，也就不容易暴跌。**要看它本来是什么性格，而不是它最近压没压紧。**

### 5. 为什么小盘股贴着均线一路涨容易暴雷

小盘股连续几十天几乎不回调，往往意味着筹码集中、少数资金控盘、中途没有充分换手。一旦有人松手，下面没有承接，加上涨跌停限制，容易连续跌停。大盘股的上涨背后是分散的机构资金，不容易出现这种断崖。

### 6. 为什么随行业一起的突破更靠谱

整个行业一起走，背后往往有政策、景气或机构配置这类「真逻辑」，能持续一段时间；单只股票独自走出来的形态，背后多是消息或游资，来得快也去得快。

### 7. 为什么周线多头里挑日线买点，反而不如随便哪天买

在已经上涨的趋势里，「日线回调后抬头」和「再创新高」其实是在挑这段时间里最热的时刻买入：价格更高、追的人更多，短期回落风险更大；「随便哪天买」反而是平均价格。等完美买点，实际上是在追热。

### 8. 为什么风险能复现，收益会缩水

风险（会不会暴跌）主要取决于股票的性格，比如长期波动大不大、筹码结不结构，性格很难改变，所以换一段时间照样成立。收益差别本来就很小，又容易受市场风格影响，还会被聪明钱提前交易掉；封存这两年是偏强的上涨市，高波动小盘股更吃香，「安静股收益好」这类结论被削弱也在情理之中。

## 四、对现状的启示（判断）

### 1. 研究框架升级：三个问题分开问，每个问题用对的层级

```
择时：现在该不该重仓？   → 看大盘层（周线休整后的突破、大盘发烧）
选行业：轮到哪个板块？   → 看行业层（第2波还是第3波、行业内是否一起走）
个股风控：这只要不要躲？ → 看个股层（守没守住突破位、股性、窄通道、热度）
```

第一阶段和 A/B/C 之所以有些结论看着很灵，一部分原因是把择时和选择混在了一起。用「同一天横向比」拆开以后，每条结论的真实归属才清楚。

### 2. 之前几条结论需要改读

| 原结论 | 修正后的读法 |
|---|---|
| A 股「周线休整 + 日线突破」9 年 8 胜（C） | 这是**大盘时机**的结论，不能用来在同一天里挑股票或挑板块 |
| A 股「二推可顺势、三推莫追高」（B） | 只在**行业层**成立，不要拿个股自己的波段去数推 |
| 缩波突破更稳（第一阶段） | 个股上要改成**选长期一直安静的股票**；「刚缩波」反而是风险标签 |
| 高位发烧避雷（第一阶段、Study 02） | 大盘层是择时信息；行业温度对选股没用；个股层看的是长期是否躁动，不是最近有没有放波 |

### 3. 手上能用的东西，按证据强弱分级

| 证据强度 | 内容 | 用法 |
|---|---|---|
| **强**：开发期 + 盲测都过 | 个股风控 4 条：跌破突破位要躲；刚安静的躁动股突破要小心；小盘窄通道尾部风险高；周线多头时别在日线上挑完美买点 | 当**过滤器**，剔除高危股票 |
| **中**：开发期强，但对应的行业指数封存区在第一阶段已用过，这条结论本身没在封存区考过 | 行业层第 2 波强于第 3 波 | 行业轮动的参考 |
| **弱**：方向一致，但有效样本少 | 大盘发烧、周线休整后突破 | 择时参考，不能重押 |

所有规则带来的收益差别都没有达到 `0.8%` 的交易门槛。**它们的价值在于少踩雷，不在于多赚钱。**

### 4. 数据纪律现状

美股 `2020–2026`、A 股行业 `2024.11–2026.11`、A 股个股 `2024.11–2026.11` 三个封存区都已经用过一次。以后提出任何新想法，都需要新的干净考场（见 `docs/backlog_research_directions.md` 的数据说明）。

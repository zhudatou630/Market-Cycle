# Phase 1A 轨道 B 角色复审：从基础状态表示退回结构解析候选

## 1. 文档定位

本文是对 [Phase 1A 路径优先级再审](phase1a-path-primacy-question.md) 的进一步架构意见，供后续 agent、研究者和决策记录参考。

本文不直接修改 D-011、D-012 或现行工作协议，也不根据少量图表宣布轨道 A 已胜出、轨道 B 已失败。它主要回答一个更具体的问题：

> 当前轨道 B 是否被安排到了错误的系统层级？它是否本来更适合作为后期路径、摆动和形态结构的基础工具，而不是与轨道 A 并列承担基础连续状态表示？

**后续结果**：本文的系统分层建议被 D-013 采纳。D-011/D-012 的基础轨道角色已被
替代；当前 ATR 路径保留为 `structures` 下的 Phase 2 候选。本文其余内容保留为外部
架构复审的论证与边界说明。

## 2. 核心结论

当前更合理的架构判断是：

1. **轨道 A 更接近基础连续行为表示。**它用固定窗口、多尺度特征持续刻画当前价格过程的方向性、效率、双向性和扩张程度，天然适合作为初级状态证据底图。
2. **轨道 B 更接近结构解析工具的早期原型。**它通过候选极值、反转确认和锚点更新，把连续价格组织成因果摆动路径，适合为后续的腿、回调、区间边界、三推、双底、通道等结构对象提供候选节点和时间契约。
3. **两者不宜长期被理解为同职能、同层级的基础表示。**轨道 B 的重置、锯齿和确认延迟不是轨道 A 的另一种连续测量风格，而是结构解析器的自然属性。
4. **仍应坚持“时间参考系显式化”，但不应预设“路径分段基础化”。**所有测量都必须说明自己相对于什么历史成立；这不等于所有基础特征都必须先经过显式摆动分段。
5. **当前轨道 B 的实现仍有研究价值。**它已经建立候选、失效、确认、生效和 `as_of` 分离的因果契约，并可作为 Phase 2 的结构候选、负面对照或工程资产保留；但不应因已有投入而自动成为未来形态层的正式骨架。

简化表达为：

```text
轨道 A：连续传感器阵列
轨道 B：结构解析器候选
```

## 3. 为什么当初会把路径提前到 Phase 1A

当初把显式路径提前，有一个真实且重要的方法论动机：项目曾计划讨论以下对象：

```text
当前腿效率
顺势回调深度
当前 Episode 年龄
平衡后首次逃逸的后续路径
```

这些对象都隐含一个起点或路径范围。如果没有显式定义，研究者很容易依赖事后看图选择“这段腿从哪里开始”，从而产生：

- 隐式分段；
- 循环定义；
- 未来确认回填；
- 状态结果反向选择最有利锚点。

D-011 因此要求固定窗口和最小因果路径正面对照。这个问题识别本身是正确的。

但当时的建议在架构优先级上发生了**过度纠偏**。从“腿相对特征需要显式路径”进一步推到了“路径表示应提前成为基础轨道”，忽略了一个更简单的解决方案：

> 基础阶段先不研究任何依赖显式腿、Episode 或摆动边界的特征；只研究固定窗口、多尺度、无需结构起点的连续行为量。腿、回调和形态统一延后。

正确的逻辑本应是二选一：

```text
方案一：
基础阶段只研究不依赖路径的连续特征；
所有腿相对语义延后。

方案二：
若基础阶段坚持研究当前腿、回调和 Episode，
则必须同步引入因果路径参考系。
```

此前建议过早选择了方案二。当前开发观察表明，方案一可能更符合项目的阶段目标。

## 4. 必须区分的三个命题

### 4.1 所有测量都需要时间参考系

这个命题成立。

固定窗口效率的参考系是：

```text
最近 n 个交易日
```

锚定路径效率的参考系是：

```text
某个候选或确认锚点至今
```

任何测量都必须声明其窗口、锚点语义、可用时点和版本。

### 4.2 腿相对、回调相对和形态相对特征需要路径结构

这个命题也成立。

没有先定义推进腿、回调腿和结构边界，就不能严格声称计算了：

- 当前腿效率；
- 当前腿年龄；
- 回调占前一推进的比例；
- 三次推进的边际衰减；
- 双底两低点之间的结构关系。

### 4.3 因此基础市场表示必须先建立路径分段

这个命题不成立。

基础状态可以先由固定窗口、多尺度的连续行为特征刻画。只有当研究问题明确要求腿、路径起源、区间边界或形态拓扑时，才需要引入结构解析层。

因此应保留的原则是：

> **时间参考系必须显式；具体路径分段不必先验居于基础层。**

## 5. 轨道 A 与轨道 B 实际上是什么类型的部件

## 5.1 轨道 A：稠密连续行为场

轨道 A 对每个有效交易日、每个预声明尺度都产生连续值。未来加入方向偏置、双向性、重叠和扩张后，它会形成：

```text
时间 × 尺度 × 行为维度
```

的连续底图。

它适合回答：

- 最近不同尺度上的路径是否直接；
- 短期方向性是否正在向中长期扩散；
- 双向性是在增加还是减少；
- 波动扩张是否伴随方向推进；
- 当前过程在多个尺度上是否一致。

这类表示不识别“当前真实腿”，但可以稳定描述截至当前的行为结构。

## 5.2 轨道 B：因果摆动参考与候选账本

`bm_g_01_atr_reversal_v1` 的核心工作不是连续测量，而是：

```text
提出候选极值
→ 新极值替换候选
→ 冻结阈值
→ 收盘越过阈值后确认反转
→ 以确认的极值作为局部路径锚点
→ 保存下一次反转候选的生命周期
```

它更准确的名称应是：

> **单尺度 ATR 阈值因果反转路径参考系。**

它提供的是局部坐标、摆动候选和事件顺序，而不是天然平滑的连续状态曲线。

每次确认反转后重新设定锚点，路径效率随坐标原点改变而跳变，是该对象类型的直接结果。要求它像 20 日效率一样平滑，等于要求结构解析器承担连续传感器的职责。

## 6. 轨道 B 当前能做什么，不能做什么

### 6.1 当前已经提供的能力

- 因果候选极值；
- 候选替换与失效记录；
- 锚点、候选、确认、生效和 `as_of` 的时间分离；
- 逐日前缀重放与批量结果一致；
- 从确认锚点开始的局部路径属性；
- 一个可审计、可否定的摆动参考基线。

这些能力是未来任何结构模块都值得继承的工程契约。

### 6.2 当前尚不能表达的结构

当前轨道 B 本身不能充分刻画：

- 震荡区间的上下边界与反复测试；
- 区间内部的价格占用和接受区域；
- 双底两个低点与中间反弹的拓扑关系；
- 三推楔形中多次推进的递减或回调加深；
- 紧密、普通和宽通道；
- 多尺度腿之间的嵌套；
- 同一摆动点在不同尺度上的结构重要性。

因此，它最多是未来形态结构层的一种**候选底层节点生成器**，不是完整形态刻画层。

## 7. 建议的系统分层

更合理的长期架构是：

```text
SPX 日线 OHLC
        ↓
共同几何与尺度层
TR / ATR / OHLC-min 路径下界等
        ↓
基础连续行为层
方向、效率、双向性、重叠、扩张
        ↓
基础市场过程表示
连续表示，或可选的初级体制压缩
        ↓
明确出现结构表达需求
腿、回调、区间边界、通道、三推、双底
        ↓
路径与形态结构层
摆动候选、价格区域、关系图、多尺度嵌套
        ↓
更丰富的 Market Cycle 表示
```

在此架构中：

```text
轨道 A 位于基础连续行为层。
轨道 B 或其后继者位于路径与形态结构层。
```

结构层可以反过来丰富或修订上层状态本体，但不再是所有基础测量的前置条件。

## 8. 对 Phase 1A 的重新解释

Phase 1A 当前工作并非没有价值。它已经形成一个重要的架构实验：

> 一个严格因果、可审计的摆动路径，是否会自然成为比固定窗口更好的连续市场状态表示？

当前观察提示，答案可能是否定的。这个负面发现有独立价值：

> 因果性和可审计性是必要条件，但不是状态表示价值的充分条件。

建议 Phase 1A 正式允许以下结论：

```text
A. 固定窗口、多尺度表示足以成为基础连续底图；
   当前 B 不进入基础状态层。

B. 当前 B 不适合作为连续状态输入，
   但候选、确认和锚点账本具有事件/审计价值，保留为后续结构资产。

C. 当前 B 的 ATR 反转定义在稳定性、延迟或语义覆盖上不足，
   记录负结论并延后；不得立即用更复杂算法挽救。

D. 两种表示或实验协议均不足，
   暂不进入状态压缩。
```

其中 B 是此前文档尚未充分正式化、但非常重要的中间结果。

## 9. 当前不建议做什么

1. 不为使轨道 B 曲线更平滑而调节 `k` 或增加平滑规则；
2. 不因为轨道 B 已经实现，就强迫其进入 Phase 1B 状态输入；
3. 不把当前 B 的负面结果扩大为“所有摆动和形态结构均无价值”；
4. 不立即引入多尺度摆动树、多个分段算法或图语法来挽救路径优先主张；
5. 不在基础阶段继续使用“当前腿效率”“当前腿年龄”等尚未由正式结构层定义的术语；
6. 不删除轨道 B 的代码、测试和候选账本，它们是后续 Phase 2 的研究资产和因果基线。

## 10. 对现有决策记录的建议

在完成现行选择块前，不必立即改写 D-011、D-012。它们记录了一个合理且可证伪的研究选择。

如果后续正式证据支持本文判断，建议新增一条决策并显式 supersede D-011 的架构优先级部分，而不是覆盖历史。新决策可以包含：

```text
1. Phase 1 的核心是固定窗口、多尺度连续行为表示；
2. Phase 1 禁止使用尚未定义路径的腿相对语义；
3. 当前最小因果路径不再与连续表示承担同层职责；
4. 路径、摆动和形态结构回到 Phase 2 专门研究；
5. bm_g_01_atr_reversal_v1 作为候选基线和因果契约资产保留；
6. Phase 2 必须从具体形态表达需求出发重新比较结构工具，
   不预设当前 ATR 路径为最终答案。
```

这不是简单恢复已被 supersede 的 D-006，而是加入一条更成熟的限制：

> 基础阶段不使用隐式腿；结构阶段也不把任意算法拐点实体化为市场本体。

## 11. 给后续 agent 的判断规则

后续 agent 在处理本问题时应遵守：

- 不因 Brooks 使用“腿、通道、楔形”等语言，就假设路径分段必须前置；
- 不因某个路径算法因果、可复现，就假设其具有连续状态价值；
- 不以视觉平滑度单独评价结构解析器；
- 不以已经投入的代码工作量决定模块是否保留；
- 不把当前 ATR 路径的失败扩大为路径结构的一般失败；
- 不允许状态结果反向移动锚点或删除失败候选；
- 任何腿相对特征必须等到正式路径/结构层建立后再命名和使用；
- 复杂结构必须证明自己补充了基础连续表示，而不只是增加解释自由度。

## 12. 最终架构判断

这两轮复审后，最清晰的系统定位是：

```text
轨道 A：
基础连续行为表示，负责持续刻画当前过程。

轨道 B：
后续结构解析候选，负责在需要时提供摆动、锚点和路径关系。
```

当初提前路径的建议正确识别了“腿相对概念不能没有显式参考系”的风险，但把解决方案过早收窄为“基础阶段必须同步建设因果路径”。更好的架构是：

> 先限制基础阶段的语义范围，只研究无需显式腿的连续特征；当区间、推进腿、回调、通道、三推和双底成为明确研究对象时，再引入路径与形态结构层。

当前轨道 B 最重要的研究贡献，可能不是证明路径应当优先，而是证明：

> **一个因果、可审计的摆动算法，并不会仅因为产生了锚点和路径，就自然成为有价值的基础市场状态表示。**

# Phase 1A E/D/B 开发审计：真实窗口语义观察

## 1. 本文性质

本文是 Phase 1A **开发块**的真实窗口人工审计记录。目的是检查固定窗口连续量
`E` / `D` / `B` 在冻结 SPX 日线上是否大致符合各自职责，并收集尺度冲突、特征互
补与反例。

本文**不是**：

- 选择块结论或锁定确认；
- 对公式“通过 / 失败”的正式判决；
- 市场状态标签、交易含义或参数优化报告；
- 把图表观感写成“连续层已足够 / 不足”的状态结论。

若观察与公式职责冲突，只记为开发期问题；是否改定义、升版本，需单独决定，不得
用路径结构模块补救。

## 2. 样本与方法

| 项目 | 值 |
|---|---|
| 快照 | `spx_daily_2026-07-21_d828fbc8` |
| 研究日表 | `...__ruler_v1_atr14w28__research.parquet` |
| 特征齐套区间 | 1984-05-01 至 2026-07-21（10637 行） |
| 窗口族 | `{5,10,20,55}` |
| 综合 | 等权；中长期优先 `(0.10,0.20,0.30,0.40)` |
| 审计主读 | 等权综合，辅读中长期与四尺度 |

方法：

1. 在全样本上计算分位、相关、尺度相关、联合分位占用；
2. 按高 / 中 / 低 `E`、强 / 弱 `|D|`、高 / 低 `B`、低尺度一致性 `A`、互补张力
   组合与历史锚点日抽样；
3. 回看对应 OHLC 窗口（至少最近 5 与 20 日过程），只记录语义是否对得上职责。

典型案例用于发现反例，**不能**替代后续连续时间选择块。

## 4. 效率 `E`：观察

**职责核对**：收盘净位移相对 OHLC 最短可见路径的直接性。

### 4.1 高 `E` 大致可读

- **1987-10-19**：`E_eq=0.565`（样本极端高），`E_5=0.85`，单边崩盘，语义正确。
- **2011-08-08 / 2015-08-24**：急跌段 `E_eq≈0.35–0.38`，短窗更高，符合“短窗抓住局部单边”。
- **1991-12-30**：年末强势上攻，`E_eq=0.437`，`B` 同步偏低——高效率单边推进。

### 4.2 低 `E` 大致可读

- **1994-03-14 / 2006-08-08 / 1985-04-29**：近乎零净位移的区间，`E_eq≈0.006–0.012`，正确。

### 4.3 中等 `E` 不等于“无方向”

持续偏多样本（`D_55>0.05` 且 `A>0.8` 且 `D_eq>0`，约 2831 日）中，`E_eq` 中位仅
约 **0.14**，`E_55` 中位约 **0.09**。慢牛 / 阶梯上行在路径长度定义下经常是
“中低效率 + 正方向”。

**开发含义**：不要把“高 `E`”口头等价成“趋势市”；`E` 量的是路径直接性，不是
方向持续性。

### 4.4 同是下跌，效率可以差很多

| 日期 | 语境 | `E_eq` | 20 日上涨日占比 | 备注 |
|---|---|---:|---:|---|
| 1987-10-19 | 黑色星期一 | 0.565 | 0.42 | 末日单边主导 |
| 2008-10-10 | GFC 急杀 | 0.241 | 0.32 | 大波动但仍有来回 |
| 2020-03-23 | 疫情底 | 0.156 | 0.32 | 窗口内剧烈双向日把路径拉长 |
| 2009-03-09 | 熊市末端 | 0.158 | 0.26 | 净跌但路径并不“干净” |

这是 `E` 与“跌得多”的刻意分离，审计上视为**符合定义**，不是缺陷。

## 5. 方向 `D`：观察

**职责核对**：ATR 标准化后的价格中心迁移速度；带符号；不是带符号效率。

### 5.1 符号与已知制度大体一致

- 急跌锚点（1987 / 2008-10 / 2011-08 / 2015-08 / 2020-03 / 2022-06）：`D_eq` 强负，
  `A≈1`（各尺度同向）。
- 慢牛片段（2017-06、2024-07）：`D_eq` 弱正至中正，`E` 并不高。
- 全样本 `D` 中位略正：样本偏置，不是公式“永远看多”。

### 5.2 与 `|E|` 高度同向，但仍有可解释残差

**`|D|` 明显高于 `E` 所预测**（残差高）：

- 多为 ATR 标准化后的陡峭漂移日（1987-10-20、2015-08-25/26、2020-02-28 等）。
- Theil-Sen / `atr_pct_14` 对“单位波动下的中心迁移”比路径效率更敏感。

**`|D|` 明显低于 `E` 所预测**（残差低）：

- 典型 **1989-10-13**：5 日暴跌抬高短窗 `E`，但 10/20 日 `D` 仍偏正（跌前上行未
  消化），等权 `D≈0`、`A=0.075`。
- 这是尺度冲突日：高短窗效率 **不等于** 综合方向强。

**开发含义**：

1. 不要把 `D` 当成“带符号的 `E`”对外讲；相关 0.80 说明幅度冗余大，但符号与
   ATR 标准化仍是独立信息。
2. 读 `D` 时 **`A` 不应省略**：约四分之一交易日 `A<0.5`，综合值可能接近 0 而
   各尺度并不安静。

### 5.3 尺度冲突 `A` 可用

低 `A` 案例语义清楚：

- **1987-12-30**：崩盘后修复，`D_5<0`、`D_20>0`，`A≈0`。
- **1998-10-14**：LTCM 低点后反弹，`D_5>0`、`D_55<0`，`A≈0.01`。
- **1995-10-05**：慢牛中的短窗回撤，`D_5<0`、`D_55>0`，`A≈0`。

短多长空、短空长多两类在样本中都大量出现（分别约 753 / 1619 日，阈值粗糙），
`A` 把“综合接近 0”从“真的没方向”里拆出来。

## 6. 双向性 `B`：观察（含主要反例）

**职责核对**：固定窗口内的双向竞争与价格再交易；应能区别于 `1-E`；设计动机包
括区分**安静停滞**与**剧烈往返**。

### 6.1 低 `B` 大致对应单边序列

- **1990-05-14 / 1987-06-22**：连续上涨，`H_5=0`，`B_eq≈0.36–0.38`（样本低分位）。
- **2001-09-21 / 2008-10-10**：连续下跌日，`H_5=0` 或很低，`B` 被短窗拉低。

短窗熵对“几乎同向收盘序列”敏感，这是 `B` 当前主要的有效变化来源。

### 6.2 高 `B` 常落在重叠大、涨跌混杂的窗口

- **1999-06-02 / 1988-07-11**：低 `E` + 高重叠 + 近五五开涨跌，`B_eq≈0.76–0.77`。
- **2008-07-14**：温和下行但 K 线重叠极高，`B_eq=0.780`（样本极高），同时
  `D_eq=-0.24`、`E_eq=0.13`。说明 `B` 不是 `1-E` 的别名，也能在有方向的窗口里
  读到“竞争激烈”——这一点与候选文档“宽通道可同时高 `D` 高 `B`”的意图相容。

### 6.3 动态范围与熵饱和（实现层警告）

| 尺度 | `B` IQR | `B` p99−p01 | `H≥0.95` 占比 |
|---|---:|---:|---:|
| 5 | 0.137 | 0.688 | 0.63 |
| 10 | 0.071 | 0.364 | 0.67 |
| 20 | 0.046 | 0.192 | **0.72** |
| 55 | **0.028** | **0.104** | **0.92** |
| equal | 0.057 | 0.271 | — |

中长窗上：

- 活跃熵几乎恒近 1（只要涨跌不是极端一边倒，二元熵就饱和）；
- `B_55` 几乎是一条窄带（中位 0.677，p01–p99 仅约 0.10）；
- 综合 `B` 的波动主要来自短窗，中长期优先综合比等权更“钝”。

### 6.4 反例：安静停滞 vs 剧烈往返几乎分不开

在 **低 `E`（`<0.06`）** 子集内按 `atr_pct_14` 取低/高 20%：

| 子集 | n | `B_eq` 中位 | `O_20` 中位 | `H_20` 中位 |
|---|---:|---:|---:|---:|
| 安静低效率 | 319 | **0.680** | 0.391 | ~0.98 |
| 剧烈低效率 | 328 | **0.668** | 0.374 | ~0.98 |

低效率内部：`B` 与 `atr` 相关约 **−0.11**（弱且方向与“剧烈→更高 B”的直觉相反或
接近零）。纯重叠均值同样分不开；`1-E` 更分不开（两边中位都约 0.95）。

**这是本轮审计对 `BM-B-01-entropy-overlap v1` 最重要的开发期反例**：

- 公式对“是否一边倒”有反应（低 `B`）；
- 对“低效率时到底是死水还是剧烈再交易”基本无分辨率；
- 根因初步判断（待改版时验证，不是本报告改码结论）：
  1. 二元涨跌熵在 `n≥20` 极易饱和，不携带波动幅度；
  2. 交并比重叠是**相对几何**量，安静小区间也可以高重叠，剧烈大摆动若跳开反
     而降低重叠。

因此，当前 `B` **尚未兑现** grill 记录里“区分安静停滞与剧烈往返”的职责表述；
它更像“涨跌是否混杂 + 区间是否彼此覆盖”的混合分，且长窗上接近常数。

### 6.5 与 `E` 的联合占用

按五分位交叉（行内占比）：

- 最高 `E` 五分位中，约 **50%** 落在最低 `B` 五分位；仅约 4% 同处最高 `B`。
- 最低 `E` 五分位中，约 **35%** 落在最高 `B`，但仍有约 5% 落在最低 `B`
  （低效率且相对单边的残留段）。

`high B ∩ high E` 全样本仅个位数级别（阈值 p90 时 6 日），属边缘；不支持把两者
当成独立正交轴，但也不等于 `B≡1-E`。

## 7. 互补与冲突：联合阅读

### 7.1 有用的三维读法（开发期）

在不升格为状态机的前提下，案例支持如下**阅读习惯**（非正式协议）：

```text
高 |D| + 高 E + 低 B + 高 A     干净的单边迁移（如 1987-10-19）
中 |D| + 中低 E + 中高 B + 高 A  有方向但路径不干净 / 通道式推进
低 |D| + 低 E + 高 B            混杂无净位移（如 1994-03）
低 |D| + 中高 E + 低 A          短窗事件 vs 长窗背景冲突（如 1989-10-13）
弱正 D + 低 E + 中 B + 高 A     慢牛阶梯（如 2024-07）
```

### 7.2 当前层仍盖不住的语义

即使 `E/D/B` 联合，审计中反复碰到但**无法用现有三维干净表达**的包括：

1. **波动扩张本身**（TR/ATR 水平跃迁、跳空、逃逸）：2020-03 与 1994-03 都可以低
   或中等 `E`，但波动制度完全不同；`B` 也分不开。这正是候选 `BM-X-01` 的缺口。
2. **结构相对位置**（是否在“当前腿”的回调中）：连续层故意不做；若问题需要它，
   属 Phase 2，不是把 `D` 改名。
3. **长窗双向性的细变化**：`B_55` 近乎常数，不能承担“季度级往返强度”读数。

### 7.3 两种综合政策

- 多数日子等权与中长期接近（相关 >0.93）。
- 中长期 `E` 系统性更低；在短窗事件日（崩盘日）等权显著更高——符合权重设计。
- `D` 约 10% 日子两综合符号不一致：图表默认双线并读仍有价值，暂未见必须废止
  某一政策的证据。

## 9. 明确不写成结论的事项

1. 不宣布 `E/D/B` 已构成市场状态，也不宣布连续层“足够 / 不足”。
2. 不因相关 0.80 而删除 `D` 或 `E`；幅度冗余与职责分工要在选择块里用信息保留
   指标再比。
3. 不因 `B` 的反例立刻改码；改定义必须升版本并重跑协议，且应先决定：
   - 是修正 `B` 的职责表述（收缩为“涨跌混杂度”），还是
   - 改公式以重新承担“安静 vs 剧烈”，或
   - 把剧烈程度交给即将设计的 `X`。
4. 不调窗口、不调权重、不引入 `tanh`、不恢复路径双轨。
5. 不把本报告案例集当作选择块时间分割。

## 10. 对下一阶段的具体建议

按优先级：

1. **保留 `E` / `D` / `A` 进入后续工作**
   开发审计未发现实现级语义崩坏；主要使用纪律是：多尺度并读、慢牛接受中低
   `E`、急跌区分“干净单边 vs 往返式崩盘”。

2. **把 `B` 标成“带已知盲区的工作版”**
   在 `docs/phase1a-working-protocol.md` / 候选目录中可补一句开发审计备注：当前
   v1 对安静/剧烈低效率分辨率不足；长窗 `B` 近乎饱和。是否改版放到 `X` 的
   grill 之后更合理——避免 `B` 与 `X` 抢“波动激烈程度”语义。

3. **下一步做扩张 `X` 的 grill**（交接原优先级第 2）
   本审计直接支撑该缺口：低 `E` 集合内波动制度差巨大，而 `B` 盖不住。候选起点
   仍是 `BM-X-01` 的 TR / Escape / Gap；Retention 只能作前向结果。

4. **选择块不要提前开**
   等 `X` 最小定义落地（或明确暂缓）并完成一次联合开发审计后，再预注册连续
   时间块与信息保留比较协议。

5. **可选工程**
   审计页：为 `B` 增加 `H_n` / `O_n` 可选序列开关，便于下一轮肉眼核对分量；非
   阻断。原生多窗格十字光标、深色主题仍非研究阻断。

# Phase 1A 状态耦合探针 v0a 审计

## 1. 当前进度与边界

本报告按
[状态耦合探针操作指南](phase1a-state-coupling-probe-operation-guide.md)执行。已依次完成
`1990-01-01` 至 `2004-12-31` 开发段、`2005-01-01` 至 `2014-12-31` 冻结检查段和
`2015-01-01` 至 `2026-07-21` 最后确认段。后两段只按冻结 `v0a` 观察，未回头修改规则。

本轮冻结底层 `E/D/B/X/clearance v1`，只评价截至当天的描述是否透明、压缩是否失真和
标签是否跳动。不计算未来收益，不把 `BALANCE_LIKE` 称为真实交易区间，也不把扩张
事件称为成功突破。

## 2. 实现与复现

已实现：

- 每个字段从首个 `ok` 值开始、只读到前一交易日的全历史因果分位；
- 五个日历年不足时输出 `insufficient_threshold_history`；
- 背景、当天事件、属性、尺度冲突、逐条证据和动态阈值的一日一行结果；
- `p25/p75`、`p35/p65` 和过去五年因果阈值对照；
- 前缀重放、未来扩展不改历史、规则性质和合成场景测试。

## 3. 开发段事实

开发段共 3,784 个正常交易日：

| 背景候选 | 日数 | 占比 |
|---|---:|---:|
| `UNRESOLVED` | 2,020 | 53.38% |
| `BALANCE_LIKE` | 838 | 22.15% |
| `DIRECTIONAL_UP` | 665 | 17.57% |
| `DIRECTIONAL_DOWN` | 261 | 6.90% |

当天事件：`EXPANSION_UP` 88 日（2.33%）、`EXPANSION_DOWN` 83 日（2.19%）、
`TURBULENT_SHOCK` 41 日（1.08%）。事件没有挤掉同日背景。

尺度冲突属性命中 52.77% 的日期。它包括低 `A`、`D_5/D_55` 异号或两种综合方向异号，
因此只是宽口径诊断，不代表一半时间都在发生状态转换。

## 4. 跳动诊断

- 背景平均连续 3.82 日，中位 2 日；
- 31.92% 的连续状态段只有一个交易日；
- 15 年共切换 989 次，年均约 66 次；
- 未出现严格的 `UP → DOWN → UP` 或 `DOWN → UP → DOWN` 三日快速翻转；
- 93.43% 的切换日，至少一条背景证据距离自身阈值不超过阈值绝对值的 5%。

最后一项是宽口径“临界证据存在”诊断，不等于已经识别出唯一的切换原因。开发段事实已足以
说明：`v0a` 硬背景标签较跳，但当前协议要求先暴露问题，不能在本版本加入平滑或滞回。

## 5. 逐步增加信息

| 步骤 | 开发段新增读数 |
|---|---:|
| `D + A` | 926 个方向候选日；1,997 个尺度冲突日 |
| `+ E` | 1,409 个低直接性日 |
| `+ entropy + overlap` | 182 个日期在不读 clearance 时已满足三项偏盘整证据 |
| `+ Activity + X` | 212 个事件日；活动属性 high / mid / low 为 1,820 / 905 / 1,059 日 |
| `+ clearance` | 最终 838 个 `BALANCE_LIKE`；其中 656 个需要 20 日覆盖补足三票 |

这些数字不是指标优劣排名。当前最值得后续复查的是：20 日历史覆盖对
`BALANCE_LIKE` 具有很高的边际影响，页面和冻结段必须明确展示它，不能只展示最终颜色。

## 6. 阈值对照

相对主规则：

| 对照 | 背景改变 | 事件改变 |
|---|---:|---:|
| `p25/p75` | 11.15% | 0.77% |
| `p35/p65` | 9.17% | 0.79% |
| 截至昨日的过去五年分位 | 7.61% | 1.06% |

小幅分位移动会改变约一成背景，但尚未达到“多数日期翻转”。这不是稳定性通过结论；需在
后两段继续用同一口径检查。全历史与五年阈值的差异不是零，老历史拖累应继续保留为审计项，
不能在本版本静默改用滚动阈值。

## 7. 开发段判断

已观察到：

1. 规则允许大量看不清，也没有让单一背景垄断开发段；
2. 扩张事件仍保持低频，背景与事件分层可正常工作；
3. 硬背景标签的单日段和切换很多，是否值得保留尚未解决；
4. clearance 对偏盘整分类影响很大，是冻结段的重点风险；
5. 小幅阈值移动造成约一成背景变化，不能称为极端脆弱，也不能称为稳定。

开发段未发现底层 v1 指标的明确实现错误或未来信息，因此未修改底层公式，也未升 probe
版本。完成组合观察页面后冻结 `v0a`，再依次打开了后两段。

## 8. 三段冻结结果

| 指标 | 1990-2004 | 2005-2014 | 2015-2026-07-21 |
|---|---:|---:|---:|
| 正常日数 | 3,784 | 2,517 | 2,903 |
| `UNRESOLVED` | 53.38% | 53.28% | 52.19% |
| `BALANCE_LIKE` | 22.15% | 17.44% | 15.81% |
| `DIRECTIONAL_UP` | 17.57% | 20.38% | 24.70% |
| `DIRECTIONAL_DOWN` | 6.90% | 8.90% | 7.30% |
| 平均连续日数 | 3.82 | 3.85 | 4.31 |
| 中位连续日数 | 2 | 2 | 3 |
| 单日状态段占比 | 31.92% | 32.47% | 30.86% |
| 尺度冲突日占比 | 52.77% | 48.71% | 48.36% |

三段背景占比没有崩塌，且始终允许约一半日期保持看不清。后段方向向上占比提高，与样本
长期偏上相容，但本报告不把它解释为预测能力。

事件占比随年代变化：向上扩张分别为 2.33% / 2.38% / 2.03%，向下扩张为
2.19% / 4.17% / 3.24%，剧烈无方向为 1.08% / 0.87% / 1.69%。2005-2014 的向下扩张
较多并未触发规则修改；它仍只是当天观察。

## 9. 跨段稳定性与残差

小幅阈值移动对背景的改变比例：

| 对照 | 1990-2004 | 2005-2014 | 2015-2026-07-21 |
|---|---:|---:|---:|
| `p25/p75` | 11.15% | 12.28% | 10.78% |
| `p35/p65` | 9.17% | 9.30% | 8.65% |
| 过去五年分位 | 7.61% | 6.67% | 6.79% |

事件在上述对照中的变化均约 0.7%-1.1%，明显小于背景。背景并非对小幅阈值移动全面
失控，但约一成日期会改变标签，这对准备充当稳定接口的硬状态仍是实质信息损失。

跳动也跨段稳定复现：每年通常切换 44-88 次，约三成状态段只有一天；三段分别有
93.43% / 94.63% / 92.42% 的切换日至少存在一条距离阈值 5% 内的背景证据。严格三日
`UP → DOWN → UP` / 反向翻转为零，说明
主要问题不是方向标签直接互打，而是候选与 `UNRESOLVED/BALANCE_LIKE` 在阈值附近频繁
切换。

20 日覆盖继续主导相当一部分偏盘整候选：三段最终 `BALANCE_LIKE` 分别为
838 / 439 / 459 日，其中在不读 clearance 时已由前三类证据解释的只有
182 / 70 / 92 日。该结果不证明 clearance 错，但说明硬标签对一个位置派生量杠杆过高，
不能只看最终颜色。

## 10. 页面审计

现有连续指标页已保留，并新增独立“组合观察”模式：

- 原始逐日背景时间带和当天事件符号；
- `D/A/E/entropy/overlap/coverage/Activity/X` 与各自因果阈值同步显示；
- 背景、事件、变化日筛选及上一个/下一个同类日期；
- `D+A → +E → +争夺 → +X → +位置` 五步观察；
- 由日表同一份结构化证据生成的命中、未命中、原始值、阈值和 margin。

桌面 1440×900 与移动 390×844 已做真实浏览器截图检查；状态带与价格日期对齐，页面无
横向溢出。事件只画符号，避免长窗口文字遮挡价格。

## 11. 最终判断

本轮结论采用操作指南的**结论 B**，并保留事件层的有效工程产物：

```text
连续向量、解释属性和当天事件值得继续保留；
v0a 硬背景候选可作为可抛弃的联读与审计脚手架；
当前不把硬背景标签提升为正式市场状态接口。
```

原因不是三段分布失控，而是硬标签没有证明压缩收益足以覆盖以下代价：约一半日期仍需
`UNRESOLVED`、约三成状态段仅一天、约一成日期对轻微阈值移动敏感，以及
`BALANCE_LIKE` 对 20 日覆盖证据的高杠杆。给 `v0a` 增加平滑、滞回或案例例外只会把
当前残差藏起来，并把静态指标问题与上下文规则混在一起，违反本轮停止条件。

本结论不删除原型及其日表；它们保留为可复现的失败边界和后续问题来源。若未来需要稳定
持续状态，应另立 `v0b` 或结构研究问题，先明确状态延续究竟解决哪类残差；不得直接在
`v0a` 上补状态机。若需要真实区间、回调、区域离开或扩张接受，应进入 Phase 2 的结构
协议，而不是继续给 `BALANCE_LIKE` 或 expansion 加语义。

- 未实现 `v0b`、滞回、状态年龄或 Episode；

字段和事件值得保留；只有提出“硬状态要服务什么接口、允许多少延迟和信息损失”后，才考虑
是否立项 `v0b`。

# Phase 1A 扩张 X：外部设计评审备忘

## 1. 希望外部审阅者回答什么

本项目准备在 SPX 日线 OHLC 的 Phase 1A 基础连续行为层中，设计“扩张” `X`。本备忘
请求审阅者评估：在不引入未来信息、路径分段或状态机的前提下，怎样定义一个技术分析
语义自洽、可审计、可反驳的最小 `X`；以及“扩张当日证据”与“突破后是否站住”该如何
分工。

请优先审查**架构与对象定义**，而非急于给参数、阈值或预测结论。一个合格答复可以主张
现有方向不值得做、`Retention` 应后置、或某个分量不应进入 Phase 1A；不需要迎合原始
候选公式。

本文件是外部评审请求，不是正式研究协议，不代表以下未决提案已被采用。

## 2. 项目边界与现行架构

### 2.1 研究对象

- 个人研究项目，不下单、不产生交易建议；
- 当前只研究 Yahoo `^GSPC` 日线 OHLC；没有可靠的指数自身成交量；
- 正式研究使用冻结快照 `spx_daily_2026-07-21_d828fbc8`；
- 共享研究表提供 `date, open, high, low, close, tr_pct, atr_pct_14`；
- 每日输出都必须声明 `as_of`，且只能读取当日及此前信息。

### 2.2 D-013 的硬边界

当前权威决定 D-013 是“基础连续行为层优先，路径结构按需后置”。Phase 1A 只研究：

```text
固定窗口、多尺度、无需显式腿或摆动边界的连续行为量。
```

Phase 1A 禁止使用当前腿、回调深度、路径年龄、Episode 起源等路径相对语义。若研究
问题确实需要腿、形态、确认摆动或交易区间的结构边界，必须在 Phase 2 建立独立、因果、
可审计的结构协议，不能静默把路径解析塞回基础层。

这项边界的完整理由见 `docs/decisions.md` 的 D-013。

### 2.3 已实现的基础层与当前缺口

当前已实现四尺度 `{5,10,20,55}` 的三个连续量：

| 量 | 职责 | 当前版本 |
|---|---|---|
| 效率 `E` | 收盘净位移有多少转为 OHLC 可见路径上的直接推进 | `BM-E-01-OHLC-min v1` |
| 方向 `D` | ATR 标准化的价格中心迁移速度 | `BM-D-01-theilsen-atr v1` |
| 双向性 `B` | 窗口内涨跌混杂与相邻 K 线再交易/重叠 | `BM-B-01-entropy-overlap v1` |

它们均有等权与中长期优先两种跨尺度综合；但它们不直接回答：

> 今天是否相对此前活动方式出现了波动放大、跳跃或离开原活动区域的失衡？

这就是 `X` 想补的语义。

最近的 E/D/B 开发审计还发现：低效率场景中，安静停滞与剧烈往返的 `B` 分数近乎不可
分；`B` 长窗也接近饱和。因此，`X` 有明确的潜在增量职责：描述波动制度或活动区域的
扩张，而不是把 `B` 改名。完整观察见
`docs/reports/phase1a-continuous-feature-development-audit.md`。

## 3. 历史候选及其未解决问题

候选目录 `docs/brooks-measurement-candidates.md` 保存了此前 ChatGPT 讨论的原式：

$$
X_t=
a_1z(TR_t)
+a_2Escape_t
+a_3z(V_t)
+a_4Gap_t
+a_5Retention_t
$$

原式意图：

| 分量 | 原始含义 | 当前可行性 |
|---|---|---|
| $z(TR_t)$ | 真实波幅异常 | 可用 OHLC 构造，但异常基线未定义 |
| $Escape_t$ | 超出原平衡边界的标准化距离 | 需要有意义、因果的原活动区边界 |
| $z(V_t)$ | 成交量或订单流异常 | 当前不可用，不能静默设为零 |
| $Gap_t$ | 跳空或连续不重叠 | 可用 OHLC 构造，但事件口径未定义 |
| $Retention_t$ | 突破幅度是否被后续保留 | 使用未来价格，只能是前向结果 |

这不是现成公式，原因包括：权重、标准化、窗口和边界均未定义；`TR`、`Gap`、
`Escape` 可能重复记录同一冲击；而 `Retention` 不能作为突破当日已知输入。候选目录
已经将 `Retention` 标为 `FORWARD_OUTCOME`，不是 `as_of=t` 特征。

## 4. 当前讨论的暂定分工

用户已明确希望保留两类输出，但要求 `X_now` 严格没有未来函数。

### 4.1 `X_now`：当日因果扩张证据

`X_now(t)` 是在 $t$ 日收盘后可得的连续行为量。它只能使用：

$$
X^{now}_t=f(\mathrm{OHLC}_{\leq t},\ \mathrm{ruler}_{\leq t},\ \mathrm{reference}_{\leq t-1})
$$

原则：

- 当日已完成的 `TR`、开盘跳空、当日收盘与此前冻结边界的关系可以使用；
- 若有“此前活动区”边界，边界必须在 $t-1$ 或更早冻结；
- 不得读取 $t+1$ 至 $t+k$ 的价格、后续是否回到旧区、后续最高/最低、未来收益或
  未来确认结果；
- `X_now` 高而后续失败是允许且应被保留的事实，不是公式错误；
- 需要以逐日前缀重放验证：批量计算的任一日期值，必须等于只提供截至该日数据的
  独立计算结果。

`X_now` 不是“趋势已经确认”。已有强趋势中的某天可以 `D/E` 高而没有新的 `X_now`；
反之，一次高 `X_now` 也可以随后失败、回到原区域或反转。

### 4.2 `Retention`：独立的前向事件结果

`Retention` 评估一场已经记录的边界外逃逸，后来保留了多少边界外进展。设：

- $b$ 是逃逸当日已冻结的边界；
- $s\in\{+1,-1\}$ 是向上/向下方向；
- 事件日 $t$ 满足 $s(C_t-b)>0$；
- $k$ 是预先指定的前向期限。

一个方向对称的单点版本可写为：

$$
Retention_{t,k}
=
\frac{s(C_{t+k}-b)}{s(C_t-b)}
$$

解释：

- 接近 $1$：突破日的边界外进展大体仍在；
- 接近 $0$：价格回到边界附近；
- 小于 $0$：价格重新进入边界内另一侧，接近失败逃逸；
- 大于 $1$：后来进一步延伸。

另一个互补结果是：

$$
TimeOutside_{t,k}
=
\frac{
\#\{i\in\{1,\ldots,k\}:s(C_{t+i}-b)>0\}
}{k}
$$

它比只看第 $k$ 日收盘更接近“后续大部分时间是否站在边界外”。

`Retention` 不是完整回调深度：它不需要此前推进起点，不记录中途最大回撤，也不衡量
回撤持续多久。它更准确地说是“边界外进展保留/接受程度”。完整回调结构仍是后续
`P` / Phase 2 问题。

时间角色必须分开保存：

```text
event_at       t：当日 X_now/escape 事件出现
boundary_at    t-1 或更早：边界已经固定
confirmed_at   t+k：Retention 结果首次可知
```

`Retention` 不得回填为 $t$ 日的 `X_now`，也不应根据它事后改变 $t$ 日的边界或事件资格。

## 5. 本次讨论中否决的简单方案

曾提出：直接把现有 `{5,10,20,55}` 窗口的此前滚动最高高/最低低当作四个“突破边界”。
这项提议已在讨论中被质疑，**不得默认采用**。

其问题不是未来函数。若边界在 $t-1$ 冻结，它完全可以因果计算。问题是其技术分析
语义过强：

```text
突破 n 日最高/最低价
不等于
突破一个已存在的交易区间、图形形态、通道或重要摆动边界。
```

5 日尤其明显：在单边趋势中连续创新 5 日高，只能说明局部新高或短期通道延伸，不能
证明此前有平衡、整理或可被称作“原活动区”的对象。

滚动最高高/最低低有真实的技术分析和趋势跟随依据：Donchian 通道与 Turtle 的 20/55
日新高/新低规则均使用它。但其正确名称应是“预设通道逃逸”或“Donchian 式突破代理”，
而不是未经证明的“真实结构突破”。若采用它，应与技术分析结构突破明确区分，且不应
因 E/D/B 使用四尺度就机械继承同一窗口族。

Brooks 风格的突破语义更强调“此前有意义的价格”--例如摆动高低点、交易区间边界、
趋势线或趋势通道。这个语义要求一个有上下文的参考区域；任意滚动极值不自动提供它。

## 6. 真正的架构张力

`X` 的两个目标之间存在张力：

| 目标 | 要求 | 风险 |
|---|---|---|
| 保持 Phase 1A 连续、简单、因果 | 固定窗口、无腿/摆动/Episode | 很难自然得到“原平衡边界” |
| 保留技术分析里的逃逸/突破语义 | 需要有意义的此前活动区或结构边界 | 容易偷偷引入状态机、路径或事后画线 |

因此，`Escape` / `Retention` 的边界至少有三种设计路线：

### A. 明确的 Donchian/预设通道代理

用预先声明的 $n$ 日最高高/最低低作为边界。优点是简单、可重复、逐日因果；缺点是
只代表通道极值，不代表真实平衡或形态突破。若选此路线，建议将其命名为
`channel_escape` / `channel_retention`，不冒充交易区间突破。

关键问题：是否只选一个或少数有明确趋势跟随依据的尺度，而非继承 `E/D/B` 的全部
窗口族？该规则对基础连续层有无独立价值，须在后续选择块比较，不能靠叙事断言。

### B. 有资格条件的固定窗口“活动区域”

先以完全因果、固定日历窗口规则判断此前窗口是否像一个活动区域，再从该区域构造边界；
只有这种区域发生逃逸时，才产生 `Escape` 和 `Retention` 事件。

潜在资格证据可包括：价格占用/重叠、宽度、方向迁移弱、对边界的重复测试或包含性。
但目前一个都没有操作定义，也不应未经讨论组合为“平衡分数”。特别是：

- 当前 `B` 对安静/剧烈低效率有盲区，不能被无条件当作区域资格；
- 若条件定义实际上是在识别状态或 Episode，应承认它越过了 Phase 1A 的边界；
- 若使用高低极值构造区域边界，需要处理一次孤立影线决定整个边界的问题；
- 量化“技术分析上有意义”的区域，可能比 `X` 本身更难。

这条路线最接近“离开原平衡区域”的原意，但也最需要严格审查是否值得其复杂度。

### C. 结构边界后置至 Phase 2

在 Phase 1A 中，`X_now` 只度量 TR 异常、Gap 和其他不需要旧区边界的扩张证据；
`Escape` / `Retention` 等 Phase 2 有明确摆动、通道或交易区间对象后再做。

这最符合 D-013 的保守边界，但会把“是否离开此前活动区域”这部分 `X` 语义后置。用户
当前希望同时保留 `X_now` 和 `Retention`，因此除非外部审阅认为这是必要的架构约束，
本项目仍希望认真评估 A 或 B 能否在不恢复路径架构的前提下成立。

## 7. 当前建议的最小研究方法（尚未决定）

以下是作者的工作建议，而非已确认方案：

1. **不要一开始压成一个加权总分。** 先保留 `TR` 扩张、Gap、Escape 等命名分量，
   因为原式权重没有依据，且分量高度可能重复。是否需要综合及如何加权，应在观察到
   分量语义、相关性和信息保留后再决定。
2. **`X_now` 与 `Retention` 严格分层。** 前者是日度因果特征；后者是独立事件的前向
   结果，不是输入、状态或当日分数。
3. **不把任意滚动极值称为真实突破。** 若使用路线 A，诚实将它作为 Donchian 型代理；
   若要使用“原活动区域”或“突破有效性”语言，必须先解决路线 B 的资格定义。
4. **不通过未来结果调 X。** 不可先按 `Retention`、未来收益或图表观感挑 TR 基线、
   边界、权重、期限或阈值。开发块可查公式和反例；正式选择须在连续时间块预注册。
5. **不恢复路径双轨或状态机。** 一份可审计的 `Retention` 事件表不应自动变成当前腿、
   Episode、趋势确认或四状态转换器。

## 8. 希望外部审阅者重点回答的问题

请按下列问题逐项给出判断、理由、替代方案和主要失败模式。

1. 在固定窗口、无路径锚点的 Phase 1A 中，路线 B 的“有资格活动区域”是否可行且有
   明确增量语义？还是它本质上已是隐含状态/结构解析，应当后置？
2. 如果采用路线 A，怎样限定尺度与命名，才能把 Donchian 型通道逃逸和技术分析中的
   交易区间/形态突破严格区分？它是否仍值得成为 `X` 的一个分量？
3. `X_now` 是否应当保持分量向量，而非在首版产生一个总分？若应综合，什么原则足以
   支撑标准化和权重，而不是任意相加？
4. 对 SPX 日线 OHLC，TR 扩张应怎样相对化才稳健、因果，并与既有 `tr_pct` /
   `atr_pct_14` 共用尺子？使用滚动 z-score、分位差、相对 ATR 或其他方法的优缺点
   分别是什么？
5. `Gap` 应取开盘越过前日范围、完整日线不重叠、实体 gap，还是完全不进入首版？其
   信息是否会与 TR 异常过度重合？
6. `Retention` 是否应在当前 Phase 1A 同步实现为独立前向事件结果？若应实现，怎样
   选择事件资格、固定期限 $k$、端点/路径口径、极小初始逃逸分母和失败定义，才能避免
   事后挑选？若不应实现，请说明应推迟到哪一个明确阶段和原因。
7. 应用哪些性质测试、前缀重放、真实窗口反例和后续选择块比较，才能证明 `X` 相对
   `E/D/B` 真有语义增量，而不是重新包装波动、方向或双向性？
8. 是否存在更简单且更贴近 Brooks “失衡/扩张”概念的 OHLC-only 表示，能避免上述
   边界语义困境？请同时指出它牺牲了什么。

## 9. 审阅时请避免的路径

- 不要把未校准连续分数称为概率或置信度；
- 不要以未来收益最大化来定义当前特征；
- 不要将未来 `Retention` 回填给突破当天；
- 不要因为已有 `bm_g_01_atr_reversal_v1` 就默认使用其路径锚点；
- 不要以“技术分析图上看起来像”替代明确、可前缀重放的边界规则；
- 不要把本项目扩展为交易系统、仓位规则、个股横截面或成交量代理研究。

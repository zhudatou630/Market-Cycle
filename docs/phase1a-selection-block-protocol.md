# Phase 1A 选择块协议

## 1. 目的与边界

本协议裁决 Phase 1A 连续字段候选集合的去留：哪些字段保留为后续市场状态表示的输入，
哪些降级为诊断字段，哪些排除并记入负结果。

**服务对象（已确认）**：本项目的描述层最终服务于真实决定——仓位与风险调整、极值风险区
识别，以及顺带的顺势/震荡姿态判断。选择块的考题由这些决定直接派生。本协议不产出交易
信号，不使用未来收益方向作为选择目标（D-004 不变）。

**开考对象**：六族连续字段——`E`（效率）、`D`（方向）、`B`（双向性）、`X`（扩张）、
clearance（旧区位置）、波动水位（待开发，暂记 `BM-V-01` 候选）。水位字段须先完成版本化
定义、性质测试与前缀重放，再与其余五族同场开考。

本文只定义裁决规则；开发块的语义审计继续遵循
[phase1a-working-protocol.md](phase1a-working-protocol.md)。

## 2. 上场比赛的代表（格子控制）

为控制多重比较，**每族每道题只派一个代表字段**：

| 族 | 代表字段 | 复核（不占格） |
|---|---|---|
| `E` | `efficiency_ohlc_min_equal` | 中长期综合、四尺度成员 |
| `D` | `direction_drift_equal_raw` | 中长期综合、四尺度成员、`A` 一致性 |
| `B` | `two_sidedness_equal_v1` | 中长期综合、四尺度成员 |
| `X` | 至多 2 个：`expansion_range_atr_prev`、`expansion_close_atr_prev` | 严格 Gap、`X_share`、活动背景 |
| clearance | `prior_range_clearance_up_55`、`prior_range_clearance_down_55` | 20 日版 |
| 水位 | `BM-V-01` 主字段（待定） | 其余尺度 |

窗口成员 `{5,10,20,55}` 不独立占格；它们的尺度一致性在稳定性关中检查。总格子约
30–40 个；**协议冻结时逐格列死，不留"到时候再看"**。

## 3. 三道考题与结果变量

### 3.1 结果变量契约

全部结果变量从 $t$ 收盘之后起算，与 $t$ 时刻特征不共享任何数据。主考前向窗口为
**20 个交易日**；5 / 55 日仅作稳健性辅读，不单独设关。

| 变量 | 定义 | 服务考题 |
|---|---|---|
| $FV20_t$ | 未来 20 日 `tr_pct` 均值 | 题一、题二 |
| $MDD20_t$ | 自 $t$ 收盘起 20 日内收盘价最大回撤（%） | 题一、题二 |
| $MRU20_t$ | 同上窗口的最大上行（%） | 题二 |
| $FE20_t$ | $t{+}20$ 时点的 $E_{20}$（未来路径直度） | 题三 |

结果变量一律用**原始百分比**，不做 ATR 归一——仓位决定关心的是原始风险。归一化版本只
作诊断辅读，不设关卡。

### 3.2 三道考题

- **题一（仓位/风险）**：按代表字段的因果分位把交易日分桶，比较各桶 $FV20$、$MDD20$
  的条件分布是否可分离。
- **题二（极值风险区）**：按字段自身因果分位取头尾极端桶（5% / 10% 两档），比较极端桶
  与中间桶的 $MDD20$、$MRU20$ **分布宽度**（双尾分别看），检验"极端读数之后局面是否更
  失控"。本题不问方向，只问宽度。
- **题三（顺势/震荡姿态）**：按代表字段分桶，比较 $FE20$ 的条件分布，检验当前读数能否
  区分未来路径的直与弯。

分位阈值只使用 $t-1$ 之前的历史（沿用 v0a 约定：满五个日历年才开始输出正常分位）。

## 4. 时间段划分

沿用 v0a 三段，不重切：

```text
开发段     1990-01-01 ~ 2004-12-31   自由观察、登记假设；其结论一律不算数
冻结检查段 2005-01-01 ~ 2014-12-31   协议冻结后只跑一遍
确认段     2015-01-01 ~ 2026-07-21   最后只跑一遍，出正式结论
```

1990 之前用于因果分位的历史积累。开发段已被既有审计观察过，这是三段制存在的原因。

## 5. 零模型

**主零模型：时间错位法。** 保持真实特征序列不动，将结果变量序列循环平移一个随机偏移
（300–3000 个交易日），重算全部格子的统计量；重复约 1000 次。保留波动聚集，只破坏
"特征—未来"的对齐。回绕跨界处丢弃。

**压力测试：块自助重建。** 以 20 日整块随机拼接真实日 K 线为假市场，在假市场上从头重算
全部特征与结果变量，完整重跑三道考题；重复约 100 次。用于检验流水线是否会在"只有短期
波动聚集"的世界里无中生有。

**最大值约定**：每次重复记录所有格子统计量的最大值，形成"运气冠军"分布。family-wise
及格线由此自动给出，无需手工数格子。

## 6. 及格线与判决

每个格子报两个数：Spearman 秩相关（主统计量，进零分布比较）与三桶中位数比（效应量，
供人读）。题二改用分布宽度比（$MDD20$、$MRU20$ 分开）。

一个字段要**保留**，须在至少一道题上同时通过三关：

| 关 | 及格线 |
|---|---|
| 显著性 | 相对"运气冠军"零分布的 family-wise $p<0.05$ |
| 稳定性 | 三段时间块内效应方向一致，且最强段与最弱段的效应量比值 $\le 3$ |
| 增量价值 | 控制土基线后仍有方向一致的增量。题一土基线：波动水位；题三土基线：当日 $E$ |

判决分三档：**保留**（进状态输入候选）、**降级为诊断**（显著但无增量，留审计页）、
**排除**（记入负结果，不在本轮挽救）。

## 7. 计数与停止纪律

1. 开发段每测一条假设都登记进假设册；
2. 字段在任一关失败 → 记负结果；要挽救必须升 feature version，留待下一轮，不在本轮
   调参救场；
3. 冻结检查段对整个格子清单只跑一遍；
4. 确认段只跑一次，无论结果如何都出报告；
5. 协议冻结时附完整格子清单与假设册；零分布的最大值约定只对已声明格子负责。

## 8. 产出物

1. 六族字段的判决表（保留 / 降级 / 排除，含三关证据）；
2. 负结果记录（失败假设也是研究资产）；
3. 对 H-001 的明确回答：连续层是否足以作为状态压缩底图，或缺少何种语义；
4. 若保留字段非空，进入 Phase 1B 的压缩价值比较（连续向量 / +事件账本 / 概率隐状态
   影子模型），比较协议另立。

## 9. 当前未决项

- `BM-V-01` 波动水位的具体公式（窗口与分位口径），开发块内另行定稿；
- 格子清单的逐格终版（冻结前列死）；
- 效应量"实际意义"参考线（如中位数比达到多少对仓位决定有实际意义），执行时给建议值。

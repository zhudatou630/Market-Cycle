# Brooks 测量与结构候选目录

## 1. 文档定位

本文保存历史研究对话中提出的 Brooks Market Cycle 公式和结构化候选，避免后续
研究从空白重新发明定义。公式主要来自本地私有归档中的对话 10、对话 15 和对话
16。归档文件位于 `docs/references/`，不提交到公开仓库。

本文不是公式规范。公式来自历史 AI 研究提案，未经本项目实证验证；保留原式不
表示接受其变量、权重、阈值或概率解释。正式实验仍由
[research-plan.md](research-plan.md) 选择候选、补足定义、固定版本和验证。

### 1.1 阅读约定

- **原式**：按归档对话保留数学结构；只统一 Markdown 排版，不静默修正。
- **原说明**：归档对话对变量意图的解释。
- **补充审查**：当前项目对数据可用性、因果时点和定义完整性的判断。
- 原式中符号可能与其他章节重名。例如这里的成熟度 `M_t` 与
  [foundation.md](foundation.md) 中用作一般记忆的 `M_t` 不是同一对象。
- 示例尺度和系数不是项目默认值；没有来源依据的权重不能直接进入实现。

### 1.2 候选状态

| 状态 | 含义 |
|---|---|
| `SOURCE_CANDIDATE` | 原对话提出，尚未补足为可运行定义 |
| `PHASE1_CANDIDATE` | 当前 OHLC 和基础阶段可以研究，但仍未采用 |
| `STRUCTURE_CANDIDATE` | 只在 Phase 2 的明确路径或形态问题中研究；必须预注册完整时点与参数规则 |
| `FORWARD_OUTCOME` | 使用未来路径，只能作结果或在未来时点确认 |
| `DEFERRED_STRUCTURAL` | 依赖 Episode、腿、通道、多尺度摆动或形态结构，等待明确结构协议 |
| `UNAVAILABLE_INPUT` | 依赖当前数据没有的 volume、订单流或盘中路径 |
| `REJECTED` | 已有明确理由不再考虑；保留记录而不删除原式 |

一个候选可以同时具有多个状态。例如突破保留既是 `SOURCE_CANDIDATE`，又是
`FORWARD_OUTCOME`。

### 1.3 时点规则

每个量必须标明其在什么时候可得：

```text
anchor_at       可选的几何追溯点，不等于当时已经知道
candidate_at    算法首次提出候选的时点
confirmed_at    候选获得确认的时点
effective_at    协议允许下游使用的起始时点
invalidated_at  候选失效的时点
as_of           本次输出时点，只能读取截至此时的数据
forward_outcome 专门用于验证，不进入当时特征
```

归档原式没有系统区分这些时间角色，本文的补充审查会显式指出。

## 2. 当前数据边界

当前数据只有 SPX 日线 `open/high/low/close`：

| 输入或结构 | 当前可用性 | 约束 |
|---|---|---|
| 收盘路径 | 可用 | 1962 年前可用于部分 close-only 研究，但不是主 OHLC 几何样本 |
| 日线实体、影线、TR、重叠 | 部分可用 | 退化 OHLC 和零区间必须经过质量门 |
| 指数自身 volume | 不可用 | 不得用 Yahoo `^GSPC` 的伪量替代 |
| 订单流和盘中成交分布 | 不可用 | 日线 OHLC 无法重建 |
| 摆动和腿 | 仅有结构候选 | 当前 ATR 反转实现保留为 Phase 2 候选，必须因果地区分候选与确认时间 |
| 价格接受 | 只能做代理 | 只能称价格占用，不能称真实成交接受 |

任何依赖边界的特征必须用 `t-1` 或更早数据建立边界；当日完整 K 线只能在当日
收盘后使用。

## 3. 六个基础行为维度

### 3.1 `BM-D-01` 方向偏置 `D`

**候选状态**：`SOURCE_CANDIDATE / DEFERRED_STRUCTURAL`

**原式**：

\[
D_t=
\tanh
\left(
\sum_k
w_k
\frac{\beta_{t,k}h_k}{ATR_{t,k}}
+
\gamma
\frac{
\sum_j s_jm_j
}{
\sum_j|m_j|
}
\right)
\]

原说明：`beta_{t,k}` 是不同周期的稳健斜率，`s_j` 是摆动方向，`m_j` 是摆动
幅度；`D_t` 接近 1 表示稳定多头偏置，接近 -1 表示稳定空头偏置。文字说明还提出
接受中心迁移方向和上下推进幅度不对称，但没有全部写进原式。

**当前 Phase 1A 版本**：`BM-D-01-theilsen-atr v1`（`PHASE1_CANDIDATE`）

只实现原式中可无结构计算的多尺度斜率项，不实现摆动不对称，也不使用 `tanh`：

$$
d_{t,n}
=
\frac{
\hat\beta^{\mathrm{Theil\text{-}Sen}}_{t,n}
}{
\operatorname{median}_{i=t-n+1}^{t}(atr\_pct_{14,i})
},
\qquad n\in\{5,10,20,55\}.
$$

其中 $\hat\beta$ 由窗口边界日到当日的 `log(close)` 点列估计；输出保留带符号
原始漂移，并附加等权 / 中长期优先综合与尺度一致性。详见
[phase1a-working-protocol.md](phase1a-working-protocol.md) 与
`.pi/grill/2026-07-25-0212——方向与双向性设计.md`。

**补充审查**：

- `w_k`、`gamma`、`h_k` 和 `ATR_{t,k}` 的具体定义及标准化没有给出；
- 摆动项不能作为 Phase 1A 连续行为层的直接公式；完整 `BM-D-01` 等待 Phase 2
  先定义结构参考系后才可条件计算；
- 当前 Phase 1A 版本是从原式拆出的无结构消融实现，不能冒充完整 `BM-D-01`；
- `tanh` 需要跨品种仍成立的饱和尺度，当前不进入正式输出；
- 方向偏置和路径效率应分开，不能用带符号效率完全替代本维度而不做比较。

### 3.2 `BM-E-01` close-only 来源式与 `BM-E-01-OHLC-min` 轨道 A 版本

**close-only 来源式状态**：`SOURCE_CANDIDATE`

**原式**：

\[
E_{t,n}
=
\frac{|C_t-C_{t-n}|}
{\sum_{i=t-n+1}^{t}|C_i-C_{i-1}|}
\]

对话 10 使用名称 `ER_t` 给出了同一结构。原意是测量市场走过的总路程中，有多少
转化成净位移；接近 1 表示高度单边，接近 0 表示大量来回运动。

**当前 Phase 1A 版本**：`BM-E-01-OHLC-min v1`（`PHASE1_CANDIDATE`）

本版本不把 close-only 原式当作实现或比较基线。它对每根日线定义与前收、OHLC 相容
的最短可见路径：

$$
L_i^{\min}
=
|O_i-C_{i-1}|
+
\min
\begin{cases}
|O_i-H_i|+|H_i-L_i|+|L_i-C_i|,\\
|O_i-L_i|+|L_i-H_i|+|H_i-C_i|.
\end{cases}
$$

再定义：

$$
E^{\mathrm{OHLC\text{-}min}}_{t,n}
=
\frac{|C_t-C_{t-n}|}
{\sum_{i=t-n+1}^{t}L_i^{\min}}.
$$

它在当前 Phase 1A 使用预声明窗口 `{5, 10, 20, 55}`，作为基础连续行为层的效率
尺度剖面，并附加等权 / 中长期优先两条跨尺度综合版本。它不识别当前腿，也不以
因果路径作为同层对照。

**补充审查**：

- 两个版本均无方向，不能用带符号效率静默替代独立方向测量；
- `L_i^{\min}` 只是 OHLC 可见路径的下界。日线 OHLC 不知道高低点的实际先后和
  中间反复，因此 `E^{\mathrm{OHLC\text{-}min}}` 是未知真实日内路径效率的上界，
  不能称为真实日内效率；
- 第一项 `|O_i-C_{i-1}|` 保留已观察的前收至开盘位移；两条内部路线只是在高低点
  未知顺序下选择较短可行序列；
- 当前 Phase 1A 已预声明 `{5, 10, 20, 55}` 窗口族；不能从中事后只留下表现最好
  的窗口，也不表示这组尺度是市场天然周期；
- 分母为零时未定义，输出缺失并标记 `zero_path`；
- 多尺度效率和效率变化趋势是原研究建议，但各尺度必须作为预声明候选保存，不能
  先看结果再选。

### 3.3 `BM-B-01` 双向性 `B`

**候选状态**：`SOURCE_CANDIDATE`；部分分量为 `PHASE1_CANDIDATE`，摆动对称为
`DEFERRED_STRUCTURAL`。

**原式**：

\[
B_t=
w_1H(\operatorname{sign}\Delta C)
+
w_2\overline{Overlap}
+
w_3Symmetry
+
w_4Crossing
\]

原说明：`H` 是上涨和下跌方向符号的熵，`Overlap` 是相邻 K 线重叠，`Symmetry`
是上下摆动幅度对称性，`Crossing` 是价格反复穿越中值或均值的次数。

对话 10 还给出了相邻 K 线重叠的原式：

\[
Overlap_t=
\frac{
\max\left(0,\min(H_t,H_{t-1})-\max(L_t,L_{t-1})\right)
}{
\min(H_t-L_t,H_{t-1}-L_{t-1})
}
\]

**当前 Phase 1A 版本**：`BM-B-01-entropy-overlap v1`（`PHASE1_CANDIDATE`）

首版只取活跃度加权二元涨跌熵与相邻 K 线**交并比**重叠：

$$
B^{v0.1}_{t,n}
=
0.5H^{active}_{t,n}
+
0.5\overline{O}^{union}_{t,n},
\qquad n\in\{5,10,20,55\}.
$$

并附加等权 / 中长期优先综合。中心穿越后置；摆动对称进入 Phase 2。详见
[phase1a-working-protocol.md](phase1a-working-protocol.md)。

**补充审查**：

- 四个分量的窗口、尺度和归一化均未定义，不能直接相加；
- `w_1` 至 `w_4` 是占位权重，不是研究结果；当前首版只用等权两项；
- 熵、K 线重叠可作为独立 Phase 1 分量；均值穿越仍待单独定义；
- `Symmetry` 需要先定义因果摆动，因此延至结构阶段；
- 原 `Overlap_t` 按较短 K 线归一化会把 inside bar 直接记为 1；Phase 1A 改用
  交并比，降低“短暂停顿 = 高度再交易”的误读；
- 双向性不是 `1-E`。净上涨且回调很深的宽通道可以同时有较高 `D` 和较高 `B`。

### 3.4 `BM-X-01` 扩张程度 `X`

**候选状态**：`SOURCE_CANDIDATE`；部分分量为 `PHASE1_CANDIDATE`，volume 分量为
`UNAVAILABLE_INPUT`，Retention 为 `FORWARD_OUTCOME` 或延迟确认量。

**原式**：

\[
X_t=
a_1z(TR_t)
+
a_2Escape_t
+
a_3z(V_t)
+
a_4Gap_t
+
a_5Retention_t
\]

原说明：`z(TR_t)` 是真实波幅异常，`Escape` 是超出原平衡边界的标准化距离，
`z(V_t)` 是成交量或订单流异常，`Gap` 是跳空或连续不重叠，`Retention` 是突破
幅度是否被保留。扩张只表示正在失衡，不等于趋势已经确认。

**补充审查**：

- 五个分量的标准化、窗口和权重没有定义；
- 当前 SPX 数据不能计算 `z(V_t)`，不能把该项静默设为零后仍称原式；
- `Escape_t` 必须相对于 `t-1` 已知的边界计算；
- `z(TR_t)`、因果 `Escape_t` 和 `Gap_t` 可作为 Phase 1 分量；
- `Retention_t` 若读取突破后的价格，只能在未来确认，不能进入突破当日的
  `as_of=t` 输出；
- Phase 1 应分别保留“当日扩张证据”和“后续是否保留”的时间角色，不把候选与
  结果混入一个总分。

### 3.5 `BM-P-01` 回调结构 `P`

**候选状态**：`SOURCE_CANDIDATE / DEFERRED_STRUCTURAL`；部分滚动代理可作为
`PHASE1_CANDIDATE`。

**原式**：

\[
P_t=
\left(
Depth,\,
Duration,\,
CounterEfficiency,\,
Recovery,\,
StructuralDamage
\right)
\]

对话 10 还提出回调深度原式：

\[
PullbackDepth=
\frac{\text{反向回撤幅度}}
{\text{此前方向推进幅度}}
\]

**补充审查**：

- 原研究明确建议保留向量而不是把回调压成单一总分，这一点应保留；
- `Depth` 和 `Duration` 也需要先定义“此前推进”的起点、方向和结束；
- `CounterEfficiency` 可沿用效率思想，但计算区间仍依赖回调 Episode；
- `Recovery` 只能随着后续原方向恢复逐步确认；
- `StructuralDamage` 必须引用已确认的摆动点或边界，属于 Phase 2；
- Phase 1 的“回调加深”只能使用预先定义的滚动或事件代理，并明确它不是完整
  `BM-P-01`。

### 3.6 `BM-M-01` 成熟与衰竭 `M`

**候选状态**：`SOURCE_CANDIDATE / DEFERRED_STRUCTURAL`

原研究先定义每段趋势推进的边际生产率：

\[
\Pi_j=
\frac{
\text{该推进创造的新极值距离}
}{
\text{该推进的路径长度或波动消耗}
}
\]

再提出成熟度结构：

\[
M_t=
f(
\text{状态年龄},
-\Delta\Pi,
\text{回调加深},
\text{失败延伸},
\text{双向性上升}
)
\]

**补充审查**：

- `f` 没有给出函数形式，因此这是变量设计图，不是可运行公式；
- 推进 `j`、新极值距离和波动消耗都需要因果路径分段；
- 状态年龄又依赖状态或 Episode 起点，不能在尚未定义状态时循环使用；
- “强趋势”和“高成熟/衰竭”可以同时成立，不能把 `M` 作为趋势强度的简单反数；
- 本候选主要进入 Phase 2。Phase 1 只能研究效率下降、回调加深和失败保留等分量，
  不应声称已经计算了完整成熟度。

## 4. 突破、保留与时间角色

### 4.1 `BM-X-RET-01` 单点突破保留率

**候选状态**：`SOURCE_CANDIDATE / FORWARD_OUTCOME`

对话 10 原式：

\[
Retention_{t,k}
=
\frac{C_{t+k}-Boundary}
{C_t-Boundary}
\]

它比较第 `k` 根后的边界外进展与突破当日进展。只要 `Boundary` 取对应方向的突破
边界，该比率对多空方向对称：空头突破时分子和分母同时为负。事件资格和“位于
边界外”的判断仍需显式保存突破方向。

### 4.2 `BM-X-RET-02` 路径突破保留率

**候选状态**：`SOURCE_CANDIDATE / FORWARD_OUTCOME`

对话 15 将保留改为整段路径：

\[
Retention_{t,k}
=
\frac1k
\sum_{i=1}^{k}
\operatorname{clip}
\left(
\frac{C_{t+i}-b}
{C_t-b},
-1,1
\right)
\]

同时提出：

\[
TimeOutside=
\frac{
\text{突破后仍位于边界外的 K 线数}
}{k}
\]

**补充审查**：

- 二者都使用 `t+1` 至 `t+k`，在 `t` 时刻不可得；
- 它们适合作为 Phase 1 前向结果，或在 `confirmed_at=t+k` 形成跟进/失败
  事件，不能回填成突破日已知特征；
- 路径比率本身对多空方向对称；`TimeOutside` 的边界外条件和事件资格仍需显式使用
  突破方向；
- 当 `C_t=b` 时分母为零，必须规定突破候选的最低非零距离；
- `clip(-1,1)` 限制极值影响，但会丢失超额延伸信息，应与未裁剪版本做明确选择；
- `k` 是事件确认尺度，不得事后从多个期限中选择最有利结果。

## 5. 价格占用与“接受”候选

### 5.1 `BM-A-01` 价格接受分布

**候选状态**：`SOURCE_CANDIDATE / DEFERRED_STRUCTURAL`；基于当前数据只能作为
价格占用代理。

原研究设：

\[
A_t(p)
\]

表示当前观察 Episode 中，市场在价格 `p` 附近停留或成交的密度，并提出：

\[
\mu_t^A=\int pA_t(p)\,dp
\]

\[
\sigma_t^A=
\sqrt{
\int (p-\mu_t^A)^2A_t(p)\,dp
}
\]

\[
\Omega_t=
\int
\min(A_t(p),A_{t-k}(p))\,dp
\]

\[
M_t^A=
\frac{\mu_t^A-\mu_{t-k}^A}
{\sigma_{t-k}^A}
\]

原文分别称其为接受中心、宽度、前后区域重叠和中心迁移速度。

**补充审查**：

- 原研究没有定义怎样从日线 OHLC 构造和归一化 `A_t(p)`；积分公式隐含其为可比较
  密度，实际实现必须明确价格网格、核函数、窗口或 Episode；
- 只有日线 OHLC 时，可以使用收盘密度、K 线覆盖价格次数或时间占用代理，但不能
  解释成真实成交量分布或参与者公平价值；
- 若该候选使用 Episode，其起点如果由未来摆动确认会造成回填，必须保存候选与
  确认时间；
- `Omega_t` 比较哪两个窗口或 Episode 尚未定义；
- `M_t^A` 原式没有除以 `k`，严格说是“经旧接受宽度标准化的 k 期中心位移”，
  不能跨不同 `k` 直接解释为单位时间速度；若研究速度，应另建包含 `/k` 的派生
  候选，不能静默修改原式；
- 当 `sigma_{t-k}^A=0` 时 `M_t^A` 未定义，需要质量规则或单独约定；
- `M_t^A` 与成熟度 `M_t` 符号重名，正式实现必须改用不冲突的标识；
- 该候选主要属于 Phase 2。Phase 1 可以保留简单边界和中心代理作为对照，但不能
  声称已经实现原式。

## 6. 路径骨架与形态结构候选

### 6.1 `BM-G-01` 多尺度 ATR 摆动阈值

**候选状态**：`SOURCE_CANDIDATE / STRUCTURE_CANDIDATE`；多尺度嵌套版本仍为
`DEFERRED_STRUCTURAL`。

原研究提出多个自适应阈值：

\[
\theta_k=c_k\cdot ATR_t
\]

并以

\[
c_k\in\{0.5,1,2,4\}
\]

作为示例尺度集。

**补充审查**：

- `{0.5,1,2,4}` 是历史 AI 示例，不是已确认参数；
- ATR 的窗口、阈值在一条腿形成期间是否冻结、候选转折如何确认均未定义；
- 若用未来形成的摆动点回填过去，结构会重绘；必须分别记录候选时间和确认时间；
- 单一尺度会遗漏嵌套结构，多尺度又会增加匹配和去重问题，因此必须和无骨架基线
  一起比较；
- 依据 D-013，本候选保留为 Phase 2 的单尺度、严格因果结构参考版本；它不是
  Phase 1A 连续行为层的同层对照，也不等于采用历史示例参数或完整多尺度摆动树。
- 当前已对齐的主版本是 `BM-G-01-atr-reversal v1`：用 `high/low` 更新候选极值，
  用 `close` 跨锚点日冻结的 ATR 阈值确认反转；
  $\theta_a=k\cdot C_a\cdot\mathrm{atr\_pct\_14}_a$，主版本 $k=2$，稳健性
  版本 $k\in\{1,3\}$。每次新极值留为候选；新极值替换时记录失效，收盘跨阈值
  时记录确认。确认发生在第 $t$ 日收盘后时，`confirmed_at = effective_at = as_of = t`；
  研究表首日的收盘是单一 `seed`，首次阈值离开只选择内部跟踪方向；其后首次正常
  反转确认日为 `path_ready_at`，正式路径输出自该日开始。预热不得作为市场状态输出；
  当前方向中若日内新极值与收盘反向跨阈值同日发生，可在收盘确认一次反转；每个
  交易日最多确认一次路径转换。确认日的新方向候选从 `close` 起步，下一根日线才用
  `high/low` 更新，不能把同日另一端极值假定为新路径一部分。三种预注册 $k$ 版本
  的正式比较统一从 1984-05-14 起，较早记录仅供内部审计。开发期按需计算；选定
  版本后，分别落盘每日路径快照与追加式候选账本。

### 6.2 `BM-G-02` 分段优化

**候选状态**：`SOURCE_CANDIDATE / DEFERRED_STRUCTURAL`

原研究提出：

\[
\min_{\text{segments}}
\left[
\text{路径重构误差}
+
\lambda\cdot\text{分段数量}
\right]
\]

**补充审查**：

- 重构损失、分段约束和 `lambda` 均未定义；
- 全样本最优分段通常使用未来信息，实时研究必须改成逐时点可用的在线或截至当日
  批量版本；
- 该目标表达了“信息保留与复杂度”的权衡，但不是现成算法。

### 6.3 图语法候选

原研究没有把所有形态压成公式，而是提出节点和边：

```text
节点：高点、低点、平衡区、突破点
边：推进腿、回调腿
节点属性：价格、时间、尺度、确认度
边属性：幅度、持续时间、效率、成交量、回撤、重叠、新极值
```

宽多头通道的候选约束包括：主要高低点抬升、上涨腿总体大于下跌腿、回调较深、
反向摆动具有显著幅度、结构重叠较高、中心仍缓慢上移。三推候选约束包括：三个
同方向摆动依次创造新极值，推进生产率下降、回调加深、第三次推进后跟进减弱。

**补充审查**：

- 这些是关系约束，不是已经完成的分类器；
- `显著`、`较深`、`缓慢` 等词仍需操作化；
- 当前无可靠 volume，边属性中的成交量不可用；
- 图语法属于 Phase 2，也可能暴露四阶段无法覆盖的结构，不应被迫服务于既定标签。

### 7.5 补充审查

- `Escape`、`ValueMigration`、`NewAcceptance` 等仍是概念变量；
- `Retention` 使用未来路径时不能进入突破当日匹配度；
- `M^A` 是有方向的中心迁移还是迁移幅度并不清楚，直接使用负号可能混淆多空方向；

- 四个 `mu` 不保证和为 1，也不保证互斥；
- `sigma` 的输出最初只能叫状态匹配度，不能称概率或置信度；
- 先输入由同一公式定义的特征，再用成员度证明状态“符合定义”，属于循环验证；
  有效性必须由因果复现、稳定性、语义覆盖和独立前向结果检验。

## 8. 状态向量、记忆与更新草图

### 8.1 `BM-Z-01` 连续状态向量

**候选状态**：`SOURCE_CANDIDATE`

对话 10 原式：

\[
Z_t=
(D_t,E_t,B_t,X_t,P_t,Q_t)
\]

其中 `Q_t` 在该轮对话中表示衰竭或再平衡风险；对话 15 后来把成熟与衰竭写成
`M_t`。这反映了命名演化，不应把 `Q` 和 `M` 当成两个已经确认的独立维度。

**补充审查**：

- 各分量既有标量也有向量，例如 `P_t` 原式是五维结构，不能不经定义直接拼成
  同质数值向量；
- `Z_t` 是候选组织方式，不证明六个维度已经充分；
- 正式表示可能需要同时保留连续变量、事件、图结构和原始窗口，而不是只输出
  `Z_t`。

### 8.2 `BM-U-01` 行为变化与递归平滑

**候选状态**：`SOURCE_CANDIDATE`

对话 10 先提出行为变化向量：

\[
\phi_t=
(
\Delta Direction,
\Delta Efficiency,
\Delta TwoSidedness,
\Delta Expansion,
\Delta Exhaustion
)
\]

随后提出更新草图：

\[
Z_t=
\lambda Z_{t-1}
+
(1-\lambda)\phi_t
\]

**补充审查**：

- 原式把绝对状态向量 `Z` 与变化向量 `phi` 相加，分量和量纲未必一致，是概念草图
  而非可直接实现的滤波器；
- `lambda` 的含义、范围和估计方式没有定义；
- 简单平滑可能压制真正的突变，强反向事件仍需要单独覆盖逻辑；
- 递归计算不等于 HMM 或贝叶斯更新，也不产生概率；
- 真正引入递归后，必须验证逐根计算与逐日截至当日批量重放一致。

### 8.3 `BM-U-02` 状态滞回

**候选状态**：`SOURCE_CANDIDATE`

对话 10 原式：

\[
\theta_{\text{进入趋势}}
>
\theta_{\text{退出趋势}}
\]

原意是进入与退出使用不同门槛，避免边界附近反复切换。

**补充审查**：

- 该不等式只表达滞回原则，没有指定证据变量、方向、持续时间和突变覆盖条件；
- 滞回可以提高标签稳定性，也可能掩盖迟钝和错误状态，必须与事件时点误差一起
  评价；
- 在状态本体尚未确定前，不预选具体阈值。

### 8.4 `BM-R-01` 非破坏性结构化表示

**候选状态**：`SOURCE_CANDIDATE / DEFERRED_STRUCTURAL`

对话 15 认为单一固定向量会过度压缩，提出：

\[
\mathcal R_t=
\left(
W_t,\,
G_t,\,
E_t,\,
Z_t,\,
\Pi_t
\right)
\]

原说明：

- `W_t`：近期原始数据窗口；
- `G_t`：摆动、区间和突破边界等多尺度几何结构；
- `E_t`：突破、失败等事件账本；
- `Z_t`：连续状态变量；
- `Pi_t`：不同状态或结构解释的权重。

**补充审查**：

- 此处 `E_t` 是事件账本，与 `BM-E-01` 的效率符号冲突；正式设计必须改名；
- `Pi_t` 与 `BM-M-01` 的推进生产率 `Pi_j` 也不是同一对象；
- 这是信息容器原则，不是要求 Phase 1 立即建设完整对象模型；
- 原研究对 Brooks 的最终机器形式概括为“多尺度几何图 + 价格接受场 + 连续行为
  向量 + 事件语法”。这支持结构层的长期位置，但不决定具体工具和接口。

## 9. 表示质量候选

### 9.1 `BM-V-01` 路径重构误差

**候选状态**：`SOURCE_CANDIDATE / DEFERRED_STRUCTURAL`

\[
\epsilon_t=
\frac{
\sum_i|P_i-\widehat P_i|
}{
\sum_i|P_i-\bar P|
}
\]

原意是让结构压缩丢失的信息可见。补充审查：这里的 `P_i` 在归档中表示原始价格
路径，不是 `BM-P-01` 的回调结构 `P_t`；正式实验应改用 `Price_i` 等无冲突符号，
但不能回改上面的原式。其采样范围、重构方法和零分母处理也尚未定义；低价格误差
不保证腿、边界和事件关系被正确保留，因此需要结构性指标和案例审计配合。

### 9.2 `BM-V-02` 历史残余信息

原研究提出检验：

\[
I(Y;H_t\mid\mathcal R_t)>0
\]

其中 `H_t` 是完整历史，`R_t` 是压缩表示。若知道 `R_t` 后，完整历史仍稳定改善
目标 `Y`，说明表示遗漏了相关信息。

补充审查：条件互信息在连续、非平稳、单一时间序列上不能直接精确读取；需要明确
目标、残差信息模型、时间分块和强基线。它是验证原则，不是现成通过门槛。

## 11. 候选进入正式实验的流程

1. 从目录中指定候选 ID，不从归档长文临时挑公式；
2. 补足所有窗口、标准化、边界、权重、零分母和方向约定；
3. 按第 1.3 节标记 `as_of` 和适用的候选、确认、失效字段，或标为 `forward_outcome`；
4. 检查当前数据是否支持，不能静默删除不可用分量后沿用原公式名称；
5. 建立公式版本和参数版本，保存数据哈希；
6. 在开发样本迭代，进入锁定样本前冻结；
7. 与原始分量、简单基线和合理替代定义做消融；
8. 记录接受、延后或拒绝，不从目录删除失败候选。

最终被选中的公式应进入当次研究协议和代码测试。本文继续负责保存设计空间、来源
和失败历史，不负责宣告哪一条公式已经有效。

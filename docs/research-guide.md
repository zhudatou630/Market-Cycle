# 市场周期项目研究操作指南

## 1. 这篇指南解决什么问题

这是一篇面向研究者的第一阅读入口。它不详细定义公式，也不记录全部假说，而是
回答五个实际问题：

1. 项目最终想得到什么；
2. 当前应该从哪个子模块开始；
3. 为什么按这个顺序研究；
4. 每个阶段应产生什么，而不只是写出什么代码；
5. 结果成功或失败后，下一步分别往哪里走。

本文只负责导航，不拥有新的研究事实。发生冲突时：

- 概念和边界以 [foundation.md](foundation.md) 为准；
- 当前假说、阶段和开放问题以 [research-plan.md](research-plan.md) 为准；
- 候选公式以 [brooks-measurement-candidates.md](brooks-measurement-candidates.md)
  为准；
- 已确认选择以 [decisions.md](decisions.md) 为准；
- 实际行为以代码和测试为准。

本文也不是进度日志。项目当前做到哪里，始终查看
[research-plan.md 的“当前阶段”](research-plan.md#1-当前阶段)。

## 2. 项目最终想得到什么

项目希望建立一种市场上下文与状态表示：把截至当前的大量价格和市场信息，压缩成
较小、可解释、可复现的结构，让人或下游策略知道：

- 当前价格过程更接近平衡、扩张、方向持续还是再平衡；
- 这个判断依赖哪些测量、事件和历史路径；
- 哪些证据支持它，哪些证据与它冲突；
- 什么新信息会加强、削弱或否定当前判断；
- 这种表示是否比简单趋势和波动指标多保留了有用信息。

它不是一开始就生产买卖信号，也不是把 Brooks 和 O'Neil 规则机械翻译成一个总分。
状态描述、条件行为和交易决策是三个不同层次。

当前实际范围比远期目标小得多：只有 SPX 日线 OHLC 数据层，研究优先从 Brooks
Market Cycle 开始。完整复刻 Brooks 还是建立 Brooks-inspired 表示，仍是
[Q-001](research-plan.md#q-001-研究目标是-brooks-复刻还是-brooks-inspired-表示)。

## 3. 为什么必须分阶段

这个项目容易同时吸引很多东西：四状态、形态、ZigZag、多尺度、HMM、个股、宽度、
领导股、O'Neil 和交易策略。如果同时展开，任何结果都很难诊断：不知道是数据、
公式、状态定义、路径提取还是统计验证出了问题。

分阶段不是预先断言哪种表示正确，而是建立可比较的基线：

- 不同时保留固定窗口基线，就不知道路径分段究竟增加了什么；
- 不尽早显式测试路径参考系，腿、回调和 Episode 会以未定义形式混入基础特征；
- 没有因果回放，漂亮的历史状态可能全部来自未来重绘；
- 没有前向结果和强基线，图上“合理”无法证明表示有研究价值；
- 没有先做单序列诊断，扩展到个股和横截面只会放大混乱。

所以整体顺序是：先比较固定窗口与最小因果路径表示，再压缩状态，再研究高级形态，
最后扩展研究对象。

## 4. 整体研究地图

```text
Phase 0  数据快照与质量边界
    ↓
Phase 1A 价格过程表示比较
    ├─ 固定窗口、多尺度表示
    └─ 最小因果路径表示
              ↓
    ├─ 至少一种表示成立 ─→ Phase 1B 可选状态压缩
    └─ 实验无效 ─────────→ 修正后重做
              ↓
Phase 2  SPX 高级路径与形态结构实验
    ↓
Phase 3  少量异质指数冻结验证
    ↓
Phase 4  高流动性个股压力测试
    ↓
Phase 5  全市场、行业和领导群体的周期分布与迁移流
    ↓
Phase 6  O'Neil M、宽度、领导力和独立成交量代理
    ↓
Phase 7  Market Context 与策略政策、风险和组合接口
```

这里有两个关键点：

1. 固定窗口和最小因果路径都是候选参考系，谁都不是默认真相；
2. Phase 1A 就检验显式路径是否有增量，Phase 2 只研究更复杂的多尺度与形态结构。

任何阶段都可以得出负结论。路线图描述研究顺序，不承诺所有模块最终都值得保留。

## 5. 每个阶段都使用同一个研究循环

无论研究一个效率变量、一个突破事件还是一种摆动骨架，都按同一循环推进：

### 5.1 明确问题

先说明这个模块要补充哪类信息。例如研究路径效率，是为了测量净位移与实际路程；
研究摆动骨架，是为了表达滚动窗口无法保留的推进腿、回调腿和层级关系。

### 5.2 继承候选，而不是从头发明

Brooks 测量先从 `BM-*` 候选目录选择。保留原研究资产，同时检查该候选是否依赖
未来、volume、摆动或尚未定义的权重。

### 5.3 补足操作定义

把窗口、边界、标准化、方向、零分母、可用时点和参数全部写清楚。此时产生的是
某个版本的研究定义，不是永恒正确的公式。

### 5.4 先证明工程上可信

确认数据快照可追溯；逐日计算与截至当日批量重放一致；候选、确认和失效时间不会
被未来数据重写。

### 5.5 再检验研究含义

所有表示都比较简单基线、跨时间块稳定性和合理参数范围。普通固定窗口测量只检查
公式、窗口语义、因果重放和信息保留；只有具有明确候选、确认和独立样本单位的
路径事件才比较事件后的前向路径。典型图表用于调试，不是正式通过证据。

### 5.6 明确做出处理

每轮研究协议应为候选记录一种处理结论：

```text
采用：进入本轮研究协议
拆分：只保留其中可解释的分量
延后：需要后续结构或数据
拒绝：当前定义不值得继续
```

这不替代候选目录中可以并存的来源、阶段、输入和时点状态。失败候选不从目录删除，
因为失败本身也是研究资产。

## 6. Phase 0：数据快照与质量边界

### 为什么先做

后续很多特征依赖 K 线区间、重叠和 TR。SPX 早期存在退化 OHLC，缓存又可能被
刷新覆盖。如果不先固定数据边界，公式是否有效与输入是否有效会混在一起。

### 主要工作

- 固定 parquet 哈希、抓取截止日和质量规则；
- 标记退化 OHLC、零区间及其影响的滚动窗口；
- 决定主研究样本和敏感性样本；
- 保留完整原始数据，不在数据层伪造或删除历史事实。

### 阶段产物

- 数据质量报告；
- 可复现的数据快照标识；
- 研究层样本资格规则。

### 进入下一阶段的条件

任意一个研究锚点都能说明自己使用了哪份数据、哪些历史窗口，以及是否满足该特征
的质量要求。

## 7. Phase 1A：价格过程表示比较

这是当前正在开发的第一个研究子模块。Phase 0 已收口（快照、质量报告、主样本
`spx_ohlc_main_1984` 与 `eligibility_v1`，见
[phase0-data-quality.md](reports/phase0-data-quality.md)）。权威状态见
[research-plan 的“当前阶段”](research-plan.md#1-当前阶段)：工作协议 v0.1 与两条
轨道的开发实现已经完成，下一步是开发期审计和正面对比。

### 7.1 固定窗口表示

第一条轨道在 `{5, 10, 20, 55}` 等预声明窗口上测量方向、路径效率、双向性和扩张。
路径效率采用 `BM-E-01-OHLC-min v1`：收盘净位移相对于 OHLC 已强制要求的最短可见
路径，而非归档中的 close-only 原式。它回答“最近 n 日怎样”，不识别当前腿，也不
直接计算 Market Cycle 总分。公式从[候选目录](brooks-measurement-candidates.md)选择；正式范围由
[research-plan 第 5 节](research-plan.md#5-phase-1a价格过程表示比较)所有。

多个窗口共同构成尺度剖面，不能事后只留下最好看的窗口。

### 7.2 最小因果路径表示

第二条轨道采用 `bm_g_01_atr_reversal_v1`：`high/low` 更新候选极值，收盘跨越锚点
日冻结的 ATR 阈值才确认反转；主版本 $k=2$，稳健性版本 $k\in\{1,3\}$。它不寻找
真实趋势起点，只提出一个可复现的路径参考系，并记录几何锚点、首次识别、确认和
失效时间。从该锚点计算路径效率、最大反向运动和年龄，不能用后来形成的转折点回填
过去。

### 7.3 正面对比

比较两套表示的因果复现、参数稳定、检测延迟、信息保留、Brooks 语义覆盖和复杂度。
只有明确路径事件才比较事件后的保留和失败；固定窗口值不承担逐日预测状态转换的
义务。工作协议可以在开发期显式迭代，但进入锁定确认块前必须冻结定义、参数、主
假说、结果、基线和停止条件。

### 阶段产物

面向人的完成信号是：能够明确说出固定窗口是否足够、最小因果路径是否有稳定增量、
路径表示是否失败，或实验是否因因果和数据问题无效。正式产物清单只维护在
[research-plan 第 9 节](research-plan.md#9-本阶段预期产物)。

## 8. Phase 1A 之后怎样分叉

### 情况一：固定窗口足够

保留多尺度连续表示，不把 Episode 设为 Brooks 模块的核心对象。可以进入 Phase 1B
比较是否值得压缩成状态。

### 情况二：最小因果路径有稳定增量

同时保留固定窗口基线和路径表示。Phase 1B 的状态候选必须读取两类证据，Phase 2
再判断高级形态是否继续增加信息。

### 情况三：路径表示不稳定

记录当前路径定义的负结论，不立即用多个分段算法、形态和例外规则挽救。是否继续
Phase 1B 取决于固定窗口表示是否仍有稳定、清楚的描述价值。

### 情况四：因果回放或数据质量不成立

这不是研究上的负结论，而是实验无效。先返回 Phase 0 或公式实现，修正后重新运行，
不能继续解释状态结果。

## 9. Phase 1B：状态压缩

这一阶段才回答“是否需要状态标签”。比较对象包括：

```text
Phase 1A 保留的原始表示
BALANCE / DIRECTIONAL 持续体制 + 转换事件
四阶段 + UNRESOLVED
```

状态压缩的目标不是凭空增加信息，而是用可接受的信息损失换取：

- 更稳定的时间序列；
- 更清楚的阶段和转换；
- 更容易审计的解释；
- 更适合作为下游接口的表达；
- 对模糊和冲突证据的诚实处理。

若离散状态丢失大量排序和路径信息，又没有带来稳定或解释价值，就保留连续表示。
四阶段不是项目必须交付的功能。

## 10. Phase 2：高级路径与形态结构

Phase 2 仍在 SPX 日线上进行，但不再负责第一次检验路径分段。它以 Phase 1A 的
固定窗口基线和最小因果路径结果为起点，研究：

- Episode 起源和关键边界；
- 推进腿与回调腿；
- 紧密、普通和宽通道；
- 多次推进、三推和边际生产率；
- 回调逐步加深、通道弱化和成熟过程；
- 多尺度结构嵌套。

候选包括多尺度 Directional Change、分段线性表示、多尺度摆动结构和图语法。
工具选择见
[Q-009](research-plan.md#q-009-phase-2-采用哪种高级路径与形态表示)。

这一阶段不能只问“预测是否提高”，还要问：

- Brooks 语义是否覆盖得更完整；
- 不同执行者或算法能否复现腿和 Episode；
- 原始路径信息是否得到更多保留；
- 参数变化后结构是否稳定；
- 候选和确认时间是否严格不重绘；
- 增加的复杂度是否值得。

按照 `research-plan`，Phase 2 结束后重新检查 Phase 1B 的状态本体，因为新结构
可能表明原状态过粗、组织方式错误，或者根本不值得离散化。

## 11. Phase 3 至 Phase 7：从局部表示走向市场上下文

### Phase 3：少量异质指数

冻结 SPX 上的定义，不在新指数上重新调到好看，检查语义和条件行为能否迁移。
失败说明外部有效性有限，不自动否定 SPX 内部结果。

### Phase 4：高流动性个股

研究公司事件、跳空、流动性和更强噪声下，个体 Market Cycle 是否仍可复现。指数
上的清晰结构不能直接外推到个股。

### Phase 5：周期分布与迁移流

对个股、行业和领导群体独立估计后，再聚合状态存量、启动、持续、衰减和反向流。
这一步才开始形成比传统均线宽度更细的市场内部结构。

### Phase 6：O'Neil M

引入独立成交量、市场宽度、领导力和多指数信息，研究调整、反弹尝试、FTD、确认
上涨和供给侵蚀。O'Neil 与 Brooks 独立估计、联合解释，不能互相修改原始分类。

### Phase 7：Market Context

将多个估计器、事件、分歧和数据质量组织成时点一致的上下文快照。只有此后才讨论
策略如何读取上下文、怎样影响风险预算；状态模块仍不直接生成订单。

## 12. 当前应该做的第一批工作

当前不要同时规划状态机、Phase 2 高级形态和后续阶段代码。Phase 0 已完成。第一批
剩余工作按以下顺序闭环：

1. ~~形成正式数据质量报告和快照标识~~（已完成）；
2. ~~写工作协议初稿并预留开发、选择和锁定确认块~~（已完成，见
   [phase1a-working-protocol.md](phase1a-working-protocol.md)）；
3. ~~补足固定窗口表示与最小因果路径的操作定义~~（已完成）；
4. ~~在开发块实现两种表示及其因果重放测试~~（已完成）；
5. 在开发块审计真实窗口，比较信息保留、语义覆盖、检测延迟、参数稳定性与复杂度；
6. 使用选择块确定固定窗口足够、路径有增量或路径定义应拒绝；
7. 在查看确认块前冻结参考系、公式、参数、主假说、结果、基线和停止条件；
8. 一次性运行锁定确认，完成预先声明的因果、稳定性和时间依赖检查；
9. 写出固定窗口足够、路径表示有增量、路径表示失败或实验无效的结论，再决定是否
   进入 Phase 1B。

研究协议和冻结时点的详细要求见
[research-plan 第 5.6 节](research-plan.md#56-基线与因果验证)，阶段正式产物见
[research-plan 第 9 节](research-plan.md#9-本阶段预期产物)。

第一个真正的完成标志不是出现一条彩色状态曲线，而是：

> 对任意一天和任意测量，都能说明采用了哪个时间参考系、当时知道什么、后来才
> 确认什么；并能说明因果路径表示相对固定窗口到底多保留了什么信息。
